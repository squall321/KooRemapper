# Tape 점탄성 vs 탄성 압축 거동 비교 연구

## 1. 개요

알루미늄 판 사이에 끼인 얇은 접착 테이프 층의 압축 거동을 LS-DYNA explicit 해석으로 비교하였다.

- **MAT_VISCOELASTIC (MAT_006)**: 속도 의존 물성 — 빠른 하중에서 높은 순간 강성 발현
- **MAT_ELASTIC (MAT_001)**: 속도 비의존 — 평형(장시간) 탄성계수만 사용

**핵심 결론**: 5 ms half-sine 하중 하에서 점탄성 테이프는 100 MPa에서도 6.2% 압축으로 건재하나, 동일 평형 탄성계수를 가진 탄성 테이프는 50 MPa부터 요소 붕괴(negative volume)로 해석 실패한다.

## 2. 모델 구성

### 2.1 형상

| 항목 | 값 |
| --- | --- |
| In-plane 메쉬 | 3 x 3 요소 (요소당 0.1 mm) |
| 전체 면적 | 0.3 mm x 0.3 mm |
| 하부 알루미늄 | 10 um (1 요소) |
| 테이프 | 30 um (1 요소) |
| 상부 알루미늄 | 10 um (1 요소) |
| 총 요소 수 | 27 (8절점 육면체, ELFORM=1) |
| 총 절점 수 | 64 |

### 2.2 경계조건

- **하면 (z=0)**: 전체 병진 자유도 구속 (XYZ 고정)
- **상면 (z=50 um)**: `*LOAD_SEGMENT_SET`으로 half-sine 압력 하중 인가
- Conformal mesh (절점 공유) — 테이프와 알루미늄이 완전 접착 상태

### 2.3 하중

- Half-sine 압력 펄스: P(t) = P_max * sin(pi * t / T)
- 하중 지속시간 T = 5 ms, 총 해석시간 = 6 ms (1 ms 자유 진동 포함)
- 하중 수준: 0.02, 0.04, 0.08, 0.16, 1, 5, 10, 50, 100 MPa

### 2.4 단위계

mm, s, ton -> 힘 = N, 응력 = MPa, 밀도 = ton/mm^3

### 3.1 알루미늄 — *MAT_ELASTIC (MAT_001)

| PR | 0.33 | 포아송비 |

### 3.2 테이프 (점탄성) — *MAT_VISCOELASTIC (MAT_006)

단일 Maxwell 요소 점탄성 모델 (MID=2).

```
*MAT_VISCOELASTIC
$      MID        RO      BULK        G0        GI      BETA
         2 1.100e-09    2000.0    0.3000    0.0100     500.0
```

| 변수 | 값 | 설명 |
| --- | --- | --- |
| MID | 2 | 물성 ID |
| RO | 1.1e-9 ton/mm^3 | 밀도 (1100 kg/m^3, 아크릴 PSA 기준) |
| BULK | 2000 MPa | 체적 탄성계수 (비압축성에 가까움) |
| G0 | 0.30 MPa | **단시간(순간) 전단 탄성계수** |
| GI | 0.01 MPa | **장시간(평형) 전단 탄성계수** |
| BETA | 500 /s | **감쇄 상수** (이완시간 tau = 1/BETA = 2 ms) |

#### MAT_006 카드 포맷 (LS-DYNA Vol II 참조)

| 필드 | 변수 | 타입 | 설명 |
| --- | --- | --- | --- |
| 1 | MID | A | 물성 식별 번호 |
| 2 | RO | F | 질량 밀도 |
| 3 | BULK | F | 체적 탄성계수. 음수이면 abs(BULK)가 온도 의존 곡선 ID |
| 4 | G0 | F | 단시간 전단 탄성계수. 음수이면 곡선 ID |
| 5 | GI | F | 장시간 전단 탄성계수. 음수이면 곡선 ID |
| 6 | BETA | F | 감쇄 상수 (1/s). 음수이면 곡선 ID |

#### 구성 방정식: 전단 이완 함수

```
G(t) = GI + (G0 - GI) * exp(-BETA * t)
```

- t=0 (순간): G = G0 = 0.30 MPa -> E_inst ~ 3*G0 = **0.90 MPa**
- t=infinity (평형): G = GI = 0.01 MPa -> E_equil ~ 3*GI = **0.03 MPa**
- 체적 응답은 순수 탄성 (BULK에 의해 지배)
- Jaumann 응력률 정식화 사용, 편차 응력에 콘볼루션 적분 적용
- 솔리드, 셸, 빔(Hughes-Liu) 요소에 사용 가능

### 3.3 테이프 (탄성) — *MAT_ELASTIC (MAT_001)

평형 탄성계수를 사용한 비교용 모델 (MID=2).

```
*MAT_ELASTIC
$      MID        RO         E        PR        DA        DB  NOT_USED
         2 1.100e-09    0.0300    0.4990       0.0       0.0       0.0
```

| 변수 | 값 | 설명 |
| --- | --- | --- |
| MID | 2 | 물성 ID |
| RO | 1.1e-9 ton/mm^3 | 점탄성과 동일 밀도 |
| E | 0.03 MPa | 영률 = 3 * GI (장시간 평형 탄성계수) |
| PR | 0.499 | 포아송비 (비압축성에 가까움) |

**주의**: K = E / (3*(1-2*nu)) = 0.03 / 0.006 = **5 MPa**. 이는 점탄성의 BULK(2000 MPa)보다 400배 작다. 탄성 모델은 체적 강성도 크게 낮다.

## 4. G0, GI, BETA의 물리적 의미와 시간 대역별 특성

### 4.1 핵심 개념

MAT_VISCOELASTIC의 세 파라미터가 결정하는 것:

- **G0 (단시간 전단 탄성계수)**: 하중이 극히 빠를 때 (충격, us 단위) 재료가 느끼는 강성. 높을수록 순간 하중에 강하다.
- **GI (장시간 전단 탄성계수)**: 하중이 충분히 오래 유지될 때 (정적, s~min 단위) 재료의 최종 강성. 접착 테이프는 이 값이 매우 작아서 "물렁물렁"하다.
- **BETA (감쇄 상수)**: 이완 속도. **tau = 1/BETA**가 이완 시간이다. 이 시간보다 빠른 하중에는 G0에 가까운 강성을 보이고, 느린 하중에는 GI에 가까운 강성을 보인다.

### 4.2 시간에 따른 유효 전단 탄성계수 G(t)

본 연구의 BETA = 500/s이므로 이완시간 tau = 2 ms이다.

| 시간 t | G(t) (MPa) | E ~ 3G (MPa) | G0 대비 | 의미 |
| --- | --- | --- | --- | --- |
| 0 ms | 0.3000 | 0.9000 | 100% | 순간 (충격 하중) |
| 0.1 ms | 0.2859 | 0.8576 | 95.3% | 극초단 하중 |
| 0.5 ms | 0.2359 | 0.7076 | 78.6% | 극초단 하중 |
| 1.0 ms | 0.1859 | 0.5577 | 62.0% | **본 해석 대역** |
| **2.0 ms** | **0.1167** | **0.3501** | **38.9%** | **본 해석 대역 (tau)** |
| **2.5 ms** | **0.0931** | **0.2793** | **31.0%** | **피크 하중 시점** |
| 5.0 ms | 0.0338 | 0.1014 | 11.3% | 하중 종료 시점 |
| 10 ms | 0.0120 | 0.0359 | 4.0% | 평형 근접 |
| 20 ms 이상 | 0.0100 | 0.0300 | 3.3% | 완전 평형 (= GI) |

**해석**: 5 ms half-sine 하중의 피크(t=2.5ms)에서 유효 전단 탄성계수는 G=0.093 MPa로, 순간값(0.3)의 31%이지만 평형값(0.01)의 **9.3배**이다. 즉, 탄성 모델(E=0.03 MPa)보다 약 **9배 강한 전단 강성**을 유지한다.

### 4.3 BETA 값에 따른 거동 변화 (참고)

| BETA (/s) | tau (ms) | 5ms 하중에서의 거동 |
| --- | --- | --- |
| 50 | 20 | tau >> T_load: 거의 순간 강성 유지 (G ~ G0) |
| 200 | 5 | tau ~ T_load: 하중 중 중간까지 이완 |
| **500** | **2** | **tau < T_load: 본 연구. 상당 부분 이완되지만 여전히 GI보다 훨씬 강함** |
| 2000 | 0.5 | tau << T_load: 빠르게 이완, 거의 평형 거동 (G ~ GI) |
| 10000 | 0.1 | 사실상 탄성 (평형) 거동과 동일 |

**설계 지침**: 원하는 하중 시간대역(T_load)보다 이완시간(tau=1/BETA)이 충분히 길면(tau > T_load), 점탄성 재료는 순간 강성(G0)에 가깝게 거동하여 변형을 억제한다.

## 6. 해석 및 토의

### 6.1 응력 전달이 동일한 이유

등분포 압력이 상면에 작용하면, 준정적 평형에서 sigma_zz = -P_applied가 전 층에 균일하게 전달된다:

1. 50 um 스택을 응력파가 통과하는 시간: ~10-40 ns (5 ms 하중에 비해 무시)
2. 하중이 공간적으로 균일 (모든 세그먼트에 동일 압력)
3. 힘의 평형: sigma_zz가 계면에서 연속

따라서 **하부 Al이 받는 응력은 테이프 물성과 무관**하며, 차이는 오직 테이프 변형에서 나타난다.

### 6.2 테이프 압축이 다른 이유: 구속 압축 상태

Conformal mesh로 테이프가 경직한 Al(E=70 GPa)에 접착되어 측면 팽창이 구속됨 -> **구속 압축(oedometric)** 상태:

```
유효 강성 = 구속 탄성계수 M = K + 4G/3
```

| 모델 | K (MPa) | G_eff (MPa) | M (MPa) | epsilon_zz = P/M |
| --- | --- | --- | --- | --- |
| 점탄성 (t~2.5ms) | 2000 | 0.093 | 2000.1 | P / 2000 |
| 탄성 | 5 | 0.01 | 5.013 | P / 5 |

M_visco / M_elastic = 2000 / 5 = **400배**. 관찰된 비율(~284배)은 하중 중 이완 효과로 약간 감소한 값이다.

**핵심**: 구속 조건에서는 **체적 탄성계수(K)**가 지배적이며, K의 400배 차이가 변형 차이의 주된 원인이다. 전단 탄성계수(G)는 M에 4G/3만큼만 기여하므로 상대적으로 영향이 작다.

### 6.3 에너지 관점에서의 해석

점탄성 모델에서는:

1. **순간 하중 시**: 높은 G0로 인해 전단 변형 에너지가 적게 저장됨
2. **하중 유지 중**: G(t)가 감소하면서 전단 응력이 이완 -> 에너지 산일 (viscous dissipation)
3. **하중 제거 후**: 남은 탄성 에너지는 GI 기반으로 작음 -> 거의 완전 회복

탄성 모델에서는:

1. 낮은 K(5 MPa)로 인해 **체적 변형 에너지**가 대량 저장
2. 에너지 산일 메커니즘 없음 -> 저장된 에너지가 모두 변형으로 전환
3. 고압에서 에너지 밀도가 요소 허용 한계를 초과 -> 요소 붕괴

## 9. 결론

1. **점탄성 테이프(MAT_006)는 100 MPa에서도 구조 건전성 유지**: 30 um -> 28.14 um (6.2% 압축). 높은 체적 탄성계수(K=2000 MPa)와 빠른 하중에서의 순간 전단 강성(G0=0.3 MPa) 덕분이다.

2. **탄성 테이프(MAT_001, 평형 탄성계수)는 중하중에서 붕괴**: 10 MPa에서 86% 압축(4.12 um), 50 MPa 이상에서 요소 뒤집힘(negative volume)으로 해석 실패.

3. **하부 Al 전달 응력은 물성과 무관**: 등분포 압축에서 sigma_zz = -P_applied가 전 층에 균일 전달.

4. **구속 조건에서 체적 탄성계수가 지배적**: conformal mesh로 Al이 측면 팽창을 구속하므로, K의 400배 차이(2000 vs 5 MPa)가 변형 차이의 주된 원인.

5. **에너지 차이**: 피크 하중에서 탄성 테이프의 내부 에너지가 점탄성 대비 100~370배 크다. 이 에너지가 모두 체적 변형으로 전환되어 요소 붕괴를 유발한다.

6. **계산 비용 동일**: MAT_006 단일 Maxwell 모델은 사이클당 추가 비용이 무시할 수준이며, 모든 정상 종료 케이스에서 ~65초로 동일하다.

7. **설계 지침**: 동적 하중을 받는 접착 테이프 모델링 시, 정적 탄성계수를 사용하면 변형을 과대 예측하고 해석이 실패할 수 있다. 점탄성 모델로 속도 의존 강성을 반영해야 현실적인 결과를 얻는다. 특히 tau = 1/BETA와 하중 지속시간(T_load)의 비율이 거동을 결정하므로, 실험 데이터로 G0, GI, BETA를 정확히 결정하는 것이 중요하다.
