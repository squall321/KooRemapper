# cnrb2solid — CNRB → solid conversion

Source: [cnrb2solid.cpp](../../src/commands/cnrb2solid.cpp)
Manual: [`KooRemapper_Manual.md`](../../docs/KooRemapper_Manual.md)


## Synopsis

```
KooRemapper cnrb2solid <args>
```

## What it does

Converts `*CONSTRAINED_NODAL_RIGID_BODY` definitions into rigid-solid representations. See [`cnrb2solid_concept.md`](../../docs/cnrb2solid_concept.md).
