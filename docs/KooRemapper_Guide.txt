================================================================
1. 개요
================================================================

KooRemapper는 LS-DYNA 메쉬 전처리 도구입니다.
디테일 메쉬 교체, 억지끼움(interference fit), 벤딩 초기응력 등을
자동 처리하고, 결과를 *INITIAL_STRESS_SOLID dynain 파일로 출력합니다.

실행:
  KooRemapper <command> [arguments...]
  KooRemapper help [command]


================================================================
2. 명령어 목록
================================================================

  assemble <config.yaml>          전체 모델 조립 (replace+squeeze+bend+indent)
  shellmap <bent> <flat> <out>    쉘 기반 솔리드 매핑
  squeeze <config.yaml>           억지끼움 초기변형
  prestress <ref> <def> <out>     변형 해석 + dynain
  map <ref> <bent> <flat> <out>   구조 메쉬 매핑
  generate <config.yaml>          가변밀도 메쉬 생성
  help [command]                  도움말


================================================================
3. assemble - 전체 모델 조립
================================================================

용도:
  전체 LS-DYNA 모델에서 특정 파트를 디테일 메쉬로 교체하거나,
  억지끼움/굽힘 초기변형을 적용하고, 모든 초기응력을 하나의 dynain으로
  누적 출력합니다.

사용법:
  KooRemapper assemble <config.yaml>

출력 파일:
  <output>.k        조립된 전체 모델 (*INCLUDE dynain 포함)
  <output>.dynain    누적 *INITIAL_STRESS_SOLID

특징:
  - *CONTACT, *BOUNDARY, *SECTION 등 모든 비파싱 키워드 보존
  - 노드/요소 ID 자동 리넘버링 (충돌 방지)
  - replace → squeeze → bend → indent 등 순차 처리 가능
  - 같은 파트에 여러 operation 적용 시 응력 자동 합산
  - 여러 파트에 대해 독립적 operation 가능

----------------------------------------------------------------
3.1 YAML 설정 포맷
----------------------------------------------------------------

  base_model: <파일경로>           # 전체 모델 .k 파일
  output: <출력접두사>             # → .k + .dynain

  operations:                     # 순차 적용할 작업 목록
    - type: replace               # 파트 교체
      target_pid: <정수>          # 교체할 파트 ID
      detail_flat: <파일경로>     # 평면 디테일 메쉬 (HEX8)
      shell_bent: <파일경로>      # 벤트 쉘 레퍼런스 (QUAD4)
      prestress: true/false       # 벤딩 초기응력 계산 (기본: false)

    - type: squeeze               # 억지끼움 초기변형
      target_pid: <정수>          # 대상 파트 ID
      eps_x: <실수>               # X방향 변형률 (음수=압축)
      eps_y: <실수>               # Y방향 변형률
      eps_z: <실수>               # Z방향 변형률

    - type: bend                   # 굽힘 변형 + 초기응력
      target_pid: <정수>          # 대상 파트 ID
      plane: xy                   # xy | yz | zx (면내 방향)
      mode: deform                # deform | stress
      source: formula             # formula | dat | dat_pair
      expression: "수식"          # source: formula 시
      dat_file: <파일경로>        # source: dat 시
      dat_top: <파일경로>         # source: dat_pair 시
      dat_bottom: <파일경로>      # source: dat_pair 시

    - type: restack               # 적층 재생성
      target_pid: <정수>          # 대상 파트 ID (extrude 형상)
      direction: auto             # auto | x | y | z (기본: auto)
      element_type: solid         # solid | tshell | shell (기본: solid)
      layers:
        - thickness: <실수>       # 층 두께
          material_card: |        # LS-DYNA 물성 카드 (MIDxxx 자리표시자)
            *MAT_ELASTIC
            $#     mid  ...
                 MID001  ...
        - thickness: <실수>
          material_card: |
            *MAT_xxx
                 MID002  ...

    - type: indent                 # 음각/양각 (indent/emboss)
      target_pid: <정수>          # 대상 파트 ID
      plane: xy                   # xy | yz | zx (면내 방향)
      direction: -z               # +z/-z, +x/-x, +y/-y (누르는 방향)
      depth: <실수>               # 양수=음각, 음수=양각(당김)
      r1: <실수>                  # 급경사 필렛 폭 (punch 쪽)
      r2: <실수>                  # 완경사 필렛 폭 (die 쪽)
      bottom_ratio: 0.0           # 선택: 하면 변위 비율 (0~1, 기본: 0)
      stress: false               # 선택: 굽힘 초기응력 (기본: false)
      shape:                      # 닫힌 루프 형상
        type: polygon             # polygon | spline
        points:                   # 면내 좌표 [x1, x2], 최소 3개
          - [3, 3]
          - [7, 3]
          - [7, 7]
          - [3, 7]

    - type: formstrain             # 셸 요소 성형 변형률
      target_pid: <정수>          # 0 = 전체 셸 파트 자동 감지
      shell_thickness: <실수>     # 선택: 셸 두께 (0=자동)
      min_curvature: <실수>       # 선택: 노이즈 필터 (기본: 0)

    - type: tet10                  # TET4 → TET10 변환
      target_pid: <정수>          # 0 = 전체 (선택)
      elform: <정수>              # ELFORM (기본: 17)

    - type: hex20                  # HEX8 → HEX20 변환
      target_pid: <정수>          # 0 = 전체 (선택)
      elform: <정수>              # ELFORM (기본: 23)

    - type: quad8                  # QUAD4 → QUAD8 변환
      target_pid: <정수>          # 0 = 전체 (선택)
      elform: <정수>              # ELFORM (기본: 23)

    - type: tria6                  # TRIA3 → TRIA6 변환
      target_pid: <정수>          # 0 = 전체 (선택)
      elform: <정수>              # ELFORM (기본: 24)

    - type: refine                 # 요소 세분화 (subdivision)
      target_pid: <정수>          # 0 = 전체 (선택)
      ratio: 2                    # 2 또는 3 (엣지 분할 수)

    - type: elform                 # ELFORM 변경 (통합)
      target_pid: <정수>          # 0 = 전체 (선택)
      target_elform: <정수/문자열> # ELFORM 번호 또는 별칭

    - type: disconnect             # 공유 노드 분리 (conformal 해제)
      mode: full                  # full | czm | mefem
      target_pid: <정수>          # 0 = 전체 (선택, 기본: 0)
      cohesive_part_id: <정수>    # [czm] cohesive 파트 ID (0=자동)
      failure_strain: <실수>      # [mefem] 파괴 소성변형률 EPPF

  dynamic_relaxation: true/false  # 선택: DR 키워드 자동 삽입 (기본: false)

  material:                       # 선택: 전체 공통 재료
    E: <실수>                     # 탄성계수 (Young's modulus)
    nu: <실수>                    # 포아송비

  * 파일 경로는 YAML 파일 기준 상대경로 또는 절대경로
  * material 미지정 시 k파일 내 *MAT_ELASTIC 사용
  * dynamic_relaxation: true 시 *CONTROL_DYNAMIC_RELAXATION,
    *CONTROL_TERMINATION(endtim=0) 자동 삽입.
    기존 *CONTROL_TERMINATION이 있으면 endtim=0으로 교체됨.

----------------------------------------------------------------
3.2 operation 상세
----------------------------------------------------------------

[replace]
  기존 파트의 coarse 메쉬를 제거하고, shellmap으로 매핑된
  디테일 메쉬를 삽입합니다.

  동작:
    1) target_pid의 요소 및 전용 노드 제거
    2) shell_bent를 평면 전개 (edge-length preserving)
    3) detail_flat를 전개면에 매핑 → 벤트 메쉬 생성
    4) 노드/요소 ID 리넘버링 (maxId + offset)
    5) 새 요소의 PID = target_pid로 설정
    6) prestress: true 시 flat→bent Green-Lagrange 초기응력 계산

  * 다른 파트와 공유되는 노드는 보존됩니다.
  * 교체된 메쉬는 독립 노드로 삽입되므로, 파트 간 연결은
    *CONTACT 등으로 별도 처리해야 합니다.

[squeeze]
  대상 파트의 노드를 바운딩박스 중심 기준으로 압축/팽창하고,
  역방향 초기응력을 dynain에 추가합니다.

  동작:
    1) target_pid의 모든 노드 수집 (replace된 노드 포함)
    2) 바운딩박스 중심(cx, cy, cz) 계산
    3) 새 좌표: new = center + (old - center) * (1 + eps)
    4) 역방향 응력: Hooke's law, strain = (-eps_x, -eps_y, -eps_z)
    5) dynain에 누적

  * replace 후 같은 파트에 squeeze 적용 가능
  * 여러 방향 동시 적용 가능 (eps_x, eps_y, eps_z)

[restack]
  한 방향으로 extrude된 파트를 다층 적층 구조로 재생성합니다.
  각 층마다 별도 물성/파트/섹션이 자동 생성됩니다.

  동작:
    1) target_pid의 요소에서 extrusion 축 자동 감지 (또는 지정)
    2) 노드를 컬럼(extrusion 방향)으로 그룹핑
    3) 기존 요소 제거, 중간 노드 제거
    4) 지정된 layer 수 만큼 새 노드 plane 생성 (선형 보간)
    5) 인접 layer는 노드 공유 (node-shared)
    6) MIDxxx 자리표시자를 실제 겹치지 않는 ID로 치환
    7) *MAT, *SECTION, *PART 카드 자동 생성
    8) 두께 합 ≠ 원본 두께 시 → squeeze 초기변형 자동 적용

  direction: auto (기본)
    - 요소 centroid 분포로 가장 얇은 축을 자동 감지
    - x, y, z 직접 지정 가능

  element_type:
    - solid (기본): *ELEMENT_SOLID + *SECTION_SOLID
    - tshell: *ELEMENT_TSHELL + *SECTION_TSHELL
    - shell: *ELEMENT_SHELL + *SECTION_SHELL (두께는 section에 기재)

  material_card:
    - LS-DYNA 물성 키워드를 통째로 YAML에 기입
    - MID001, MID002 등 자리표시자 → 기존 모델과 겹치지 않는 ID로 자동 치환
    - 같은 MIDxxx를 여러 layer에서 사용하면 같은 실제 ID로 매핑

  * extrude 형상이 아닌 파트에 적용 시 에러
  * 두께 불일치 시 dynamic_relaxation: true 권장

[bend]
  대상 파트에 굽힘(warpage/bending) 변형을 적용하고,
  Kirchhoff 판 이론 기반 초기응력을 dynain에 추가합니다.

  plane: 면내 방향
    xy → 면내 축: x, y / 법선 축(처짐 방향): z
    yz → 면내 축: y, z / 법선 축: x
    zx → 면내 축: z, x / 법선 축: y

  mode:
    deform → 노드 좌표를 굽힌 형상으로 이동 + 역방향 초기응력
             (DR 시 굽힌 상태 유지)
    stress → 좌표 변경 없음 + 순방향 초기응력
             (DR 시 평면 → 굽힘 변형)

  source: 처짐량(w) 데이터 소스

    formula (수식)
      expression 필드에 수학 수식을 직접 지정.
      변수: x1, x2 (면내좌표, BB min 기준)
            L1, L2 (BB 크기), pi
      함수: sin, cos, tan, exp, log, sqrt, abs, pow,
            asin, acos, atan, atan2, min, max
      예: "0.5 * sin(pi*x1/L1) * sin(pi*x2/L2)"

    dat (중립면 처짐 그리드)
      dat_file 필드에 공백 구분 2D 그리드 파일 지정.
      행(row) = x₂ 방향 (첫 줄=x₂_max, 마지막 줄=x₂_min)
      열(col) = x₁ 방향 (x₁_min → x₁_max)
      값 = 법선 방향 처짐량
      그리드 범위가 파트 바운딩박스에 자동 매핑.

    dat_pair (상/하면 처짐 쌍)
      dat_top, dat_bottom 필드에 각각 상면/하면 그리드 파일 지정.
      중면(midplane) 기준 곡률 계산.
      배터리 스웰링 등 상/하면 처짐이 다른 경우 사용.

  동작:
    1) plane → 면내 축(x₁, x₂), 법선 축 결정
    2) target_pid의 노드/요소 수집, 바운딩박스 계산
    3) 처짐 소스 준비 (formula→101×101 그리드 / dat→파일 로드)
    4) 곡률 계산: κ₁₁, κ₂₂, κ₁₂ (유한차분)
    5) 각 요소 중심의 굽힘 변형률: ε = -d · κ (d = 중립면 거리)
    6) Hooke's law → 응력 (deform: 역방향 / stress: 순방향)
    7) deform 모드: 노드 변위 적용
       Δn = w(x₁,x₂), Δx₁ = -d·∂w/∂x₁, Δx₂ = -d·∂w/∂x₂

  * squeeze + bend 같은 파트 적용 시 응력 자동 합산
  * Kirchhoff 면내 보정으로 두꺼운 파트도 정확
  * 변형률은 순수 굽힘 (멤브레인 변형 없음)

[indent]
  대상 파트에 임의 형상의 음각(indent) 또는 양각(emboss) 변형을
  적용합니다. Quarter-arc 필렛 프로파일로 프레스 스탬핑 형상을
  재현합니다.

  depth:
    양수 → 음각 (표면을 안쪽으로 누름)
    음수 → 양각 (표면을 바깥쪽으로 당김)

  r1, r2: 전이 영역 필렛 폭
    r1 = 급경사(punch) 쪽 필렛 (바닥에서 시작)
    r2 = 완경사(die) 쪽 필렛 (표면에서 시작)
    전이 영역 = r1 + r2 (이 범위 밖은 변위 없음)
    프로파일: quarter-arc (quarter-ellipse), C⁰ 연속

  shape: 닫힌 루프 형상 정의
    polygon → 다각형 (꼭짓점 연결)
    spline  → Catmull-Rom 폐곡선 (제어점 20개/세그먼트 보간)
    루프 내부 = 전체 깊이, 루프 외부 = 전이 후 변위 없음
    Winding Number 알고리즘으로 볼록/오목 다각형 모두 지원

  plane + direction:
    plane=xy → 면내 축: x,y / 법선(변위) 축: z
    direction=-z → z 최대면에서 아래로 누름
    direction=+z → z 최소면에서 위로 누름

  bottom_ratio: 하면 변위 비율
    0.0 (기본) → 표면만 변위, 하면 고정
    1.0 → 전체 두께 균일 변위 (리지드 이동)
    0.5 → 하면이 표면의 50% 변위

  stress: true 시
    필렛 영역의 곡률에서 Kirchhoff 판이론 기반 굽힘 응력 계산.
    κ = -h''(d) (프로파일 곡률), ε = -d·κ (d: 중립면 거리).
    역방향 초기응력 → DR로 변형 유지.
    곡률 cap: 최대 변형률 5% (singularity 방지).
    K파일 내 *MAT_ELASTIC 또는 YAML material 섹션 사용.

  동작:
    1) plane → 면내 축, 법선 축 결정
    2) shape points → ClosedLoop 구성 (polygon/spline)
    3) AABB 사전 필터링 (루프 BB + r1+r2 여유)
    4) 각 노드: signed distance → quarter-arc 변위 → through-thickness 보간
    5) stress: true → 요소별 곡률 분해 → 굽힘 응력 → dynain 누적

  * 다른 operation과 조합 가능 (squeeze + indent → 응력 합산)
  * 음각/양각 전환은 depth 부호만 변경
  * 복잡 형상은 spline으로 부드러운 경계 생성

[formstrain]
  셸 요소의 기하학적 곡률로부터 성형 변형률(EPS)을 계산하여
  *INITIAL_STRESS_SHELL 카드로 dynain에 출력합니다.

  동작:
    1) 셸 요소의 엣지 인접성(adjacency) 구축
    2) 인접 요소 간 이면각(dihedral angle) → 곡률 κ = θ/L
    3) 요소별 평균 곡률 → 굽힘 변형률 ε = κ · t/2
    4) 항복 응력(sigy) 대비 소성 변형률 EPS 계산
    5) 같은 요소의 여러 결과는 max() 병합

  target_pid: 0 (기본)
    - 0이면 모든 셸 파트를 자동 감지하여 처리
    - 특정 PID 지정 시 해당 파트만 처리

  shell_thickness: 0 (기본)
    - 0이면 K파일 내 *SECTION_SHELL에서 자동 조회
    - 양수 지정 시 해당 값을 우선 사용

  min_curvature: 0 (기본)
    - 지정된 값 미만의 곡률은 무시 (노이즈 필터)

  * 재료 정보: K파일의 *MAT_024 (MAT_PIECEWISE_LINEAR_PLASTICITY)에서
    항복 응력(sigy) 자동 조회
  * NPLANE=1, NTHICK=2 (T=-1,+1)로 쉘 적분점 설정

[tet10 / hex20 / quad8 / tria6]
  기존 1차 요소를 2차(quadratic) 요소로 변환합니다.
  각 엣지의 중점에 새 노드를 생성하고, 요소의 connectivity를 확장합니다.

  변환 종류:
    tet10  → TET4(4절점) → TET10(10절점), ELFORM 기본값 17
    hex20  → HEX8(8절점) → HEX20(20절점), ELFORM 기본값 23
    quad8  → QUAD4(4절점) → QUAD8(8절점), ELFORM 기본값 23
    tria6  → TRIA3(3절점) → TRIA6(6절점), ELFORM 기본값 24

  동작:
    1) 대상 요소 수집 (type별 필터링)
    2) 각 엣지의 중점 노드 생성 (인접 요소 간 자동 공유)
    3) 확장된 connectivity로 기존 요소 대체
    4) *SECTION_SOLID / *SECTION_SHELL의 ELFORM 자동 변경

  target_pid: 0 (기본)
    - 0이면 해당 타입의 모든 요소를 변환
    - 특정 PID 지정 시 해당 파트만 변환

  elform: 0 (기본)
    - 0이면 변환 타입별 기본값 사용
    - 양수 지정 시 해당 ELFORM 사용

  * 같은 모델에서 quad8 + tria6 조합 가능 (각각 별도 operation)
  * 엣지 중점 노드는 operation 간에도 공유 (중복 생성 없음)
  * TRIA3 감지: N4==N3 또는 N4==0 모두 지원

[refine]
  대상 파트의 요소를 1:2 또는 1:3 비율로 세분화(subdivision)합니다.
  각 엣지를 ratio등분하여 서브 요소를 생성합니다.

  지원 요소/비율:
    ┌──────────┬───────────────────────┬───────────────────────┐
    │ 요소     │ ratio: 2              │ ratio: 3              │
    ├──────────┼───────────────────────┼───────────────────────┤
    │ QUAD4    │ → 4 sub-quads         │ → 9 sub-quads         │
    │ TRIA3    │ → 4 sub-tris          │ → 9 sub-tris          │
    │ TET4     │ → 8 sub-tets          │ (미지원)              │
    │ HEX8     │ → 8 sub-hexes         │ → 27 sub-hexes        │
    └──────────┴───────────────────────┴───────────────────────┘

  ratio: 2 (기본)
    - 각 엣지를 2등분 → 면 중심 + 체심 노드 추가
    - QUAD4: 4개 엣지 중점 + 1개 면 중심 → 4 sub-quads
    - TRIA3: 3개 엣지 중점 → 4 sub-tris
    - TET4:  6개 엣지 중점 → 8 sub-tets (Bey 분할)
    - HEX8:  12개 엣지 중점 + 6개 면 중심 + 1개 체심 → 8 sub-hexes

  ratio: 3
    - 각 엣지를 3등분 → 면 내부 + 체 내부 노드 추가
    - QUAD4: 8개 엣지 삼등분점 + 4개 내부점 → 9 sub-quads
    - TRIA3: 6개 엣지 삼등분점 + 1개 중심점 → 9 sub-tris
    - HEX8:  24개 엣지 + 24개 면 내부 + 8개 체 내부 → 27 sub-hexes

  target_pid: 0 (기본)
    - 0이면 모든 지원 요소를 세분화
    - 특정 PID 지정 시 해당 파트만 세분화

  노드 공유:
    - 인접 요소가 공유하는 엣지/면의 노드는 자동 공유 (중복 없음)
    - 1:2 엣지 중점, 면 중심, 체심 모두 dedup
    - 1:3 엣지 삼등분점, 면 내부점 모두 dedup
    - HEX8 1:3의 면 내부점은 canonical bilinear 정렬로 인접 요소 간
      정확한 노드 공유 보장

  * 혼합 요소 모델에서 QUAD4+TRIA3 동시 세분화 가능
  * writeOutput 변경 불필요 (기존 removedElementIds/addedElements 메커니즘 활용)
  * 비정제 인접 파트와의 hanging node는 사용자가 별도 처리
    (*CONTACT_TIED_SURFACE_TO_SURFACE 등)

[elform]
  대상 파트의 ELFORM(요소 적분 방식)을 변경합니다.
  같은 차수 내 변경, 1차→2차 업그레이드, 2차→1차 다운그레이드를 통합 지원합니다.

  동작 모드:
    A) 같은 차수 변경 (ELFORM만 교체)
       예: HEX8 ELFORM 1→2, QUAD4 ELFORM 2→16
       *SECTION_SOLID / *SECTION_SHELL의 ELFORM 값만 변경

    B) 업그레이드 (1차→2차, mid-node 자동 생성)
       예: TET4→TET10 (ELFORM 13→17), HEX8→HEX20 (ELFORM 1→23)
       기존 tet10/hex20/quad8/tria6 operation과 동일 동작

    C) 다운그레이드 (2차→1차, mid-node 제거)
       예: TET10→TET4 (ELFORM 17→13), HEX20→HEX8 (ELFORM 23→1)
       multi-line 요소를 single-line으로 변환, 코너 노드만 유지

  target_elform: 숫자 또는 별칭(alias)으로 지정 가능

  Solid ELFORM 별칭:
    ┌────────┬────────────────────────────┬──────┬──────────┐
    │ ELFORM │ 별칭                       │ 노드 │ 적분점   │
    ├────────┼────────────────────────────┼──────┼──────────┤
    │  1     │ constant_stress            │ HEX8 │ 1        │
    │  2     │ fully_integrated           │ HEX8 │ 8        │
    │  3     │ fully_integrated_qm        │ HEX8 │ 8        │
    │ -1     │ fully_integrated_nodal     │ HEX8 │ 8        │
    │ -2     │ fully_integrated_reduced   │ HEX8 │ 8        │
    │ 13     │ tet4                       │ TET4 │ 1        │
    │ 10     │ tet4_10pt                  │ TET4 │ 10       │
    │ 60     │ tet4_60                    │ TET4 │ 1        │
    │ 17     │ tet10                      │ TET10│ 4-5      │
    │ 16     │ tet10_16                   │ TET10│ 4        │
    │ 23     │ hex20                      │ HEX20│ 27       │
    └────────┴────────────────────────────┴──────┴──────────┘

  Shell ELFORM 별칭:
    ┌────────┬────────────────────────────┬──────┬──────────┐
    │ ELFORM │ 별칭                       │ 노드 │ 적분점   │
    ├────────┼────────────────────────────┼──────┼──────────┤
    │  2     │ belytschko_tsay            │ QUAD4│ 1        │
    │ 16     │ fully_integrated_shell     │ QUAD4│ 4        │
    │  1     │ hughes_liu                 │ QUAD4│ 4        │
    │ 23     │ quad8                      │ QUAD8│ 9        │
    │ 24     │ tria6                      │ TRIA6│ 6        │
    └────────┴────────────────────────────┴──────┴──────────┘

  YAML 예:
    # 같은 차수 변경 (hourglass 제거)
    - type: elform
      target_elform: 2             # 또는 "fully_integrated"

    # 특정 파트 TET4→TET10 업그레이드
    - type: elform
      target_pid: 3
      target_elform: 17            # 또는 "tet10"

    # 2차→1차 다운그레이드
    - type: elform
      target_elform: 13            # TET10 → TET4

  * 기존 tet10/hex20/quad8/tria6 operation도 계속 동작 (backward-compatible)
  * 다운그레이드 시 mid-edge 노드는 *NODE에 남지만 참조되지 않음

[disconnect]
  Conformal(공유 노드) 메쉬에서 요소 간 노드 연결을 끊어 분리합니다.
  Peridynamics, CZM(층간 분리), MEFEM(결합 파괴) 해석에 사용합니다.

  mode 종류:

  ┌──────────┬───────────────────────────────────────────────────────────┐
  │ mode     │ 동작                                                       │
  ├──────────┼───────────────────────────────────────────────────────────┤
  │ full     │ 모든 요소를 완전 분리 (요소별 고유 노드)                  │
  │          │ Peridynamics *SECTION_SOLID_PERI (ELFORM=48) 자동 생성   │
  ├──────────┼───────────────────────────────────────────────────────────┤
  │ czm      │ 다른 파트 간 공유 면(inter-part face)만 분리              │
  │          │ 계면에 *MAT_COHESIVE_MIXED_MODE + cohesive 요소 삽입     │
  │          │ solid: ELFORM=19 (8-node), shell: ELFORM=19 (4+4-node)   │
  ├──────────┼───────────────────────────────────────────────────────────┤
  │ mefem    │ czm과 동일 선택적 분리 + tied constraint                 │
  │          │ *SET_NODE_LIST + *CONSTRAINED_TIED_NODES_FAILURE 생성     │
  └──────────┴───────────────────────────────────────────────────────────┘

  target_pid: 0 (기본) = 전체 파트 대상. 특정 파트만 지정 가능.

  cohesive_part_id: [czm] cohesive 파트 ID. 0이면 자동(maxPartId+1).
  failure_strain:   [mefem] EPPF 파괴 소성변형률. (예: 0.085)

  노드 분리 규칙 (czm/mefem):
    - inter-part 공유 면의 노드만 복제
    - PID가 낮은 파트가 원본 노드 유지 (primary)
    - PID가 높은 파트에 복제 노드 생성 (coincident 위치)
    - 같은 파트 내 연결은 유지됨 (intra-part 면은 분리 안 됨)

  지원 요소 타입:
    - HEX8, TET4 solid     → 6면/4면 face adjacency
    - QUAD4 shell (coincident faces) → 4-node face key
    - 후속 연산 (restack)으로 생성된 요소도 처리 가능

  생성 키워드 (czm):
    *MAT_COHESIVE_MIXED_MODE (placeholder 값, 사용자 수정 필요)
      EN=1.0E6, ET=1.0E6, GIC=1.0, GIIC=2.0, XMU=1.0, T=50.0, S=30.0
    *SECTION_SOLID (ELFORM=19)
    *PART (Cohesive interface)

  생성 키워드 (mefem):
    *SET_NODE_LIST (coincident 노드 쌍)
    *CONSTRAINED_TIED_NODES_FAILURE (NSID, EPPF, ETYPE=1)

  생성 키워드 (full):
    *SECTION_SOLID_PERI (ELFORM=48, DR=1.01, PTYPE=1)

  YAML 예:
    # 모드 1: Full Disconnect (Peridynamics)
    - type: disconnect
      mode: full
      target_pid: 0           # 전체

    # 모드 2: CZM (자동 cohesive 파트 생성)
    - type: disconnect
      mode: czm
      target_pid: 0
      cohesive_part_id: 0     # 자동

    # 모드 3: MEFEM (파괴 소성변형률 0.085)
    - type: disconnect
      mode: mefem
      target_pid: 0
      failure_strain: 0.085

  주의사항:
    * czm에서 생성된 *MAT_COHESIVE_MIXED_MODE는 placeholder 값.
      실제 해석 전 EN, ET, GIC, GIIC, T, S 등을 재료 시험 값으로 교체 필요.
    * full mode: 기존 *SECTION_SOLID는 *SECTION_SOLID_PERI로 교체됨.
      원본 SECTION_SOLID 삭제되고 addedKeywordBlocks에 PERI 버전 추가됨.
    * restack + czm 조합이 가장 일반적인 용도.
      restack이 각 층을 별도 파트로 생성 → czm이 층간 계면에 cohesive 삽입.

[iga]
  특정 파트를 IGA(Isogeometric Analysis) 포맷으로 고도화합니다.
  FE solid를 trivariate B-Spline NURBS box로 감싸 NURBS 기반 해석이 가능하게 합니다.
  각 대상 파트에 대해 별도 .k 파일을 생성하고 메인 파일에 *INCLUDE를 삽입합니다.

  IGA 동작 원리:
    1. 대상 파트의 바운딩 박스(BB) 계산 (노드 좌표 min/max)
    2. BB를 ±element_size로 확장 (PARAMETER_EXPRESSION_LOCAL 기반)
    3. 새 PID/SECID/MID 할당 (기존 최대값 +1)
    4. 원본 재료(MID)를 새 MID로 복사 (IGA 파일 내에만 존재)
    5. NURBS box를 정의하는 *IGA_3D_NURBS_XYZ (2×2×2 knot spans, 8 제어점) 생성
    6. 별도 .k 파일 작성 + 메인 출력에 *INCLUDE 삽입

  ⚠ 재료 MID 복사 필수:
    IGA 파트는 반드시 전용 MID를 사용해야 합니다.
    동일 MID를 IGA와 비-IGA 파트에 공유하면 LS-DYNA 오류 발생.
    KooRemapper는 자동으로 새 MID를 발급하고 원본 재료 카드를 복사합니다.
    메인 출력 파일의 원본 MID는 절대 변경되지 않습니다.

  출력 파일:
    <output>.k             메인 파일 (기존 내용 + *INCLUDE 라인 추가)
    <output>_iga_p{pid}.k  각 파트별 IGA 키워드 파일

  YAML 파라미터:

  ┌──────────────────┬──────────┬───────────────────────────────────────────────┐
  │ 파라미터          │ 기본값   │ 설명                                          │
  ├──────────────────┼──────────┼───────────────────────────────────────────────┤
  │ target_pid (필수) │ -        │ 대상 FE solid 파트 ID                         │
  │ element_size (필수)│ 1.0     │ NURBS box 복셀 크기 (rr=rs=rt 공통)           │
  │ element_size_r   │ 0 (auto) │ r방향 크기 개별 지정 (0이면 element_size 사용) │
  │ element_size_s   │ 0 (auto) │ s방향 크기 개별 지정                           │
  │ element_size_t   │ 0 (auto) │ t방향 크기 개별 지정                           │
  │ offset           │ -1 (auto)│ bbox 고정 확장량 (-1=element_size와 동일)      │
  │ bbox_scale       │ 0 (off)  │ 균일 배율: IGA박스=파트bbox×scale             │
  │                  │          │ (off=±(scale-1)/2×len, 0이면 비활성화)        │
  │ bbox_scale_r     │ 0 (auto) │ r방향 배율 개별 지정 (0이면 bbox_scale 사용)   │
  │ bbox_scale_s     │ 0 (auto) │ s방향 배율 개별 지정                           │
  │ bbox_scale_t     │ 0 (auto) │ t방향 배율 개별 지정                           │
  │ ir               │ 0        │ 적분 규칙 (0=reduced Gauss, 1=full Gauss)     │
  │ styp             │ 4        │ LCP stabilization type                        │
  │ tollg            │ 1.0e-3   │ Light Control Point 임계값                    │
  │ pr / ps / pt     │ 1        │ 각 방향 polynomial order (B-Spline 차수)       │
  │ nisr / niss / nist│ 1       │ 각 방향 적분점 수                              │
  └──────────────────┴──────────┴───────────────────────────────────────────────┘

  YAML 예:
    # 단일 파트 IGA (기본 설정)
    - type: iga
      targets:
        - target_pid: 1
          element_size: 0.6

    # 다중 파트 + 축별 크기 개별 지정
    - type: iga
      targets:
        - target_pid: 3
          element_size: 0.6     # rr=rs=rt 기본
          element_size_r: 1.0   # r방향만 다르게
          ir: 1                 # full Gauss
          pr: 2                 # 2차 polynomial
        - target_pid: 5
          element_size: 1.0

    # bbox_scale 기반 확장 (파트 크기 배율)
    - type: iga
      targets:
        - target_pid: 1
          element_size: 4.0
          bbox_scale: 1.5       # 각 방향 ±25% 확장 (IGA박스=파트bbox×1.5)
        - target_pid: 2
          element_size: 3.0
          bbox_scale_r: 2.0     # r: ±50% 확장 (off=(2-1)/2×lenR)
          bbox_scale_s: 1.3     # s: ±15% 확장
          bbox_scale_t: 1.0     # t: 확장 없음 (scale=1.0 → off=0)

  생성 키워드:
    *PARAMETER_LOCAL         (id, mid, fepid, xmin~zmax, rr~rt, ofr/ofs/oft, ir, styp, tollg)
    *PARAMETER_EXPRESSION_LOCAL (rxminn/rxmaxx/ryminn/rymaxx/rzminn/rzmaxx, &ofr/&ofs/&oft 사용)
    *MAT_*                   (원본 재료 복사, 새 MID)
    *IGA_DEV_STABILIZATION   (sid, styp, tollg)
    *PART                    (IGA_Part_{fepid}, 새 PID/SECID/MID)
    *SECTION_IGA_SOLID        (ELFORM=0)
    *IGA_DEV_VOLUME_XYZ       (TETMSH=-1, fepid=원본 파트)
    *IGA_SOLID                (nisr/niss/nist, rid)
    *IGA_3D_NURBS_XYZ         (2×2×2 knot, pr/ps/pt, 8 corner control points)
    *IGA_REFINE_SOLID         (rtyp=2, hrtyp=2, rr/rs/rt, itr=its=itt=2)

  주의사항:
    * 원본 FE solid는 메인 파일에 그대로 유지됩니다 (TETMSH=-1 임베딩).
    * IGA 해석에는 LS-DYNA IGA 라이선스가 필요합니다.
    * 생성된 *MAT_* 카드는 원본 재료 카드의 복사본이므로 IGA에 적합한지
      확인하고 필요시 수정하십시오.
    * bbox 확장 우선순위: bbox_scale_r/s/t > bbox_scale > offset >= 0 > auto(element_size).
      bbox_scale=1.5 이면 off = (1.5-1)/2×len = 0.25×len (각 방향 길이의 25%).
      offset=0.0 이면 확장 없음. offset=-1(기본)이면 element_size와 동일.
    * PARAMETER_LOCAL에 ofr/ofs/oft로 실제 사용된 offset값이 기록됩니다.

[offset]
  대상 파트의 표면에서 오프셋 레이어를 생성합니다.
  Solid/TShell/Shell 요소로 extrude하며, tied/czm/contact 연결 모드를 지원합니다.
  Dual offset prestress 모드로 pouch 감싸기(wrapping) 시뮬레이션도 가능합니다.

  주요 용도:
    - Battery pouch wrapping: 내부 압축 + 외부 릴랙스 상태 prestress
    - Thermal insulation layer: 표면에 단열재 레이어 추가
    - Coating/Cladding: 코팅 또는 클래딩 레이어 모델링
    - Multi-material stack: 연속 offset으로 다층 구조 생성

  기본 동작:
    1) source_pid의 외부 표면 자동 추출 (solid face occurrence count = 1)
    2) offset 방향 결정 (+normal/-normal/±x/±y/±z)
    3) num_layers 층만큼 노드 생성 (layer-by-layer)
    4) element_type에 따라 요소 생성 (solid/tshell/shell)
    5) connection_mode 적용 (tied/czm/contact)
    6) 새 PART/SECTION/MATERIAL 키워드 자동 생성

  파라미터:

  ┌─────────────────────────┬──────────┬──────────────────────────────────────────┐
  │ 파라미터                │ 기본값   │ 설명                                      │
  ├─────────────────────────┼──────────┼──────────────────────────────────────────┤
  │ source_pid (필수)       │ -        │ 표면을 추출할 소스 파트 ID                │
  │ thickness (필수)        │ -        │ Offset 총 두께 (mm)                       │
  │ num_layers              │ 1        │ 레이어 수 (두께 = thickness/num_layers)   │
  │ element_type            │ solid    │ solid | tshell | shell                   │
  │ offset_direction        │ +normal  │ +normal/-normal/±x/±y/±z                 │
  │ connection_mode         │ tied     │ tied | czm | contact                     │
  │ new_pid                 │ 0 (auto) │ 새 파트 ID (0=자동 증가)                  │
  │ new_secid               │ 0 (auto) │ 새 섹션 ID (0=자동 증가)                  │
  │ new_mid                 │ 0 (auto) │ 새 재료 ID (0=자동 증가)                  │
  │ part_title              │ "Offset Layer" │ 파트 제목                         │
  │ material_card           │ (없음)   │ *MAT_* 키워드 (multi-line, @MID@ 치환)   │
  │ shell_thickness         │ 0 (auto) │ Shell/TShell 두께 (0=thickness 사용)      │
  │ shell_offset            │ -1 (auto)│ Shell mid-plane 오프셋 (-1=thickness/2)  │
  │ use_local_normals       │ false    │ 노드별 법선 사용 (품질 개선, Phase 2)     │
  │ thickness_formula       │ (없음)   │ 두께 수식 (x,y,z,L1,L2,pi, Phase 4)      │
  │ bbox_xmin/xmax          │ (없음)   │ Bounding box X 범위 (Phase 3)            │
  │ bbox_ymin/ymax          │ (없음)   │ Bounding box Y 범위 (Phase 3)            │
  │ bbox_zmin/zmax          │ (없음)   │ Bounding box Z 범위 (Phase 3)            │
  │ node_id_min/max         │ (없음)   │ 노드 ID 범위 필터 (Phase 3)               │
  └─────────────────────────┴──────────┴──────────────────────────────────────────┘

  element_type 상세:

    solid (HEX8):
      - Offset 방향으로 extrude하여 solid 요소 생성
      - num_layers층의 HEX8 요소 스택
      - *SECTION_SOLID (ELFORM=1, constant stress)
      - 가장 일반적인 옵션

    tshell (TSHELL3/TSHELL4):
      - Thick shell 요소 (각 층은 top+bottom 노드 보유)
      - num_layers층의 TSHELL 요소
      - *SECTION_TSHELL (ELFORM=16 QUAD / 17 TRIA)
      - Through-thickness 변형 해석 가능

    shell (QUAD4/TRIA3):
      - 표준 shell 요소
      - Offset 위치에 단일 노드면 생성
      - *SECTION_SHELL (ELFORM=2, Belytschko-Tsay)
      - 얇은 레이어 모델링 (두께는 SECTION에만 기재)

  offset_direction 상세:

    +normal / -normal:
      - 표면 법선 벡터 평균 계산 (모든 face의 외적 평균)
      - 곡면 표면의 자연스러운 오프셋
      - +normal: 법선 방향 (외부로)
      - -normal: 법선 역방향 (내부로)

    ±x / ±y / ±z:
      - 카테시안 축 고정 방향
      - 평면 표면 또는 특정 방향 강제 시 사용
      - 예: +z는 Vector3D(0, 0, 1)

  connection_mode 상세:

  ┌──────────┬──────────────────────────────────────────────────────────────┐
  │ mode     │ 동작                                                          │
  ├──────────┼──────────────────────────────────────────────────────────────┤
  │ tied     │ 노드 공유 (기본값)                                            │
  │          │ - Source 표면 노드를 offset 레이어 하단 노드로 직접 사용      │
  │          │ - Perfect tie constraint 자동 달성                            │
  │          │ - 추가 키워드 불필요                                          │
  ├──────────┼──────────────────────────────────────────────────────────────┤
  │ czm      │ Cohesive Zone Model                                          │
  │          │ - Source 표면 노드를 복제 (동일 위치)                         │
  │          │ - Zero-thickness cohesive elements 삽입 (ELFORM=20)          │
  │          │ - *MAT_COHESIVE_* 키워드 필요 (czm_material_card)            │
  │          │ - 층간 분리(delamination) 해석                                │
  ├──────────┼──────────────────────────────────────────────────────────────┤
  │ contact  │ Contact definition (완전 분리)                                │
  │          │ - Offset 레이어 하단에 새 노드 생성 (동일 위치)               │
  │          │ - Contact definition template 주석으로 출력                   │
  │          │ - 사용자가 *CONTACT_* 키워드 수동 추가                        │
  │          │ - 비결합(unbonded) 레이어 모델링                              │
  └──────────┴──────────────────────────────────────────────────────────────┘

  Dual offset prestress 모드:

    prestress_mode: dual_offset 지정 시 활성화.
    Battery pouch wrapping 시뮬레이션에 사용.

    원리:
      1. Inner offset (음수, 압축 상태): 변형된 형상 (deformed)
      2. Outer offset (양수, 릴랙스 상태): 참조 형상 (reference)
      3. Reference 형상의 노드 좌표를 출력 (.k 파일)
      4. Deformed → Reference 간 full 3D 변형률 계산
      5. 역방향 초기응력을 dynain에 출력
      6. DR 실행 시 reference → deformed로 수축 (pouch 감싸기 재현)

    추가 파라미터:
      inner_offset: 압축 형상 오프셋 (음수, mm)
      outer_offset: 릴랙스 형상 오프셋 (양수, mm)

    변형률 계산:
      - Isoparametric mapping으로 deformation gradient F 계산
      - Full 3D strain tensor (ε_xx, ε_yy, ε_zz, ε_xy, ε_yz, ε_xz)
      - Squeeze operation과 동일한 metric tensor 방법 사용
      - Small strain approximation: ε = 0.5 * (C - I), C = F^T * F

    Connection mode와 조합:
      - tied: 원본 노드 직접 사용 (변위만 계산)
      - czm/contact: 복제 노드 inner offset 위치에 생성

  고급 기능 (Phase 2-4):

    use_local_normals (Phase 2):
      - 기본: 전역 법선 벡터 (모든 면 평균)
      - local=true: 노드별 법선 벡터 (인접 면 평균)
      - 곡면에서 품질 개선 (Jacobian +324%)
      - +normal/-normal 방향과 함께 사용

    Region Selection (Phase 3):
      - bbox_xmin/xmax/ymin/ymax/zmin/zmax: bounding box 필터
      - node_id_min/node_id_max: 노드 ID 범위 필터
      - 조합 가능 (AND 조건)
      - 예: 580 요소 → 82 요소 (90% 감소)

    Variable Thickness (Phase 4):
      - thickness_formula: 수식 기반 두께 (변수: x, y, z, L1, L2, pi)
      - 예: "1.0 + 0.02*x" → x 위치에 따라 두께 변화
      - 위치별로 다른 두께 자동 계산
      - thickness 파라미터와 병행 사용 (기본값)

  알려진 제한사항:

    1. -normal 방향: 음수 Jacobian 발생 (side surface 문제)
       → 회피: ±x/±y/±z 고정 방향 사용

    2. Shell source: 이전 operation의 shell을 source로 사용 불가
       → 회피: 중간 결과를 파일로 저장 후 base_model로 재로드

    3. TET4 source: 작동하지만 degenerate HEX8 생성 (품질 저하)
       → aspect ratio 999, warping 90° 경고
       → 향후 WEDGE6 지원으로 개선 예정

    4. +normal on concave: 오목 표면에서 self-intersection 가능
       → 회피: 고정 방향 사용 또는 region selection으로 영역 제한

  품질 개선 효과 (실측):
    - 기본 (no features): Aspect Ratio 13.33, Jacobian 0.119
    - + Local normals: AR 7.38, Jac 0.505 (+324%)
    - + Region filter: AR 6.67, Jac 0.972
    - + 모든 기능: AR 7.45, Jac 0.507 (최적)

  YAML 예:

    # 기본 solid offset (tied)
    - type: offset
      source_pid: 1
      thickness: 1.0
      num_layers: 1
      element_type: solid
      offset_direction: +z
      new_pid: 10
      part_title: "Insulation Layer"
      material_card: |
        *MAT_ELASTIC
        $#     mid        ro         e        pr
             @MID@       1.2      1000       0.3

    # TShell offset (다층)
    - type: offset
      source_pid: 1
      thickness: 2.0
      num_layers: 2
      element_type: tshell
      offset_direction: +normal
      new_pid: 11
      shell_thickness: 1.0

    # CZM connection
    - type: offset
      source_pid: 1
      thickness: 0.5
      element_type: solid
      offset_direction: +z
      connection_mode: czm
      czm_part_id: 20
      czm_mid: 100
      czm_material_card: |
        *MAT_COHESIVE_MIXED_MODE
        $#     mid        ro        en        et       gic      giic       xmu
             @MID@       1.0     1.0E6     1.0E6       1.0       2.0       1.0
        $#       t         s
                50.0      30.0

    # Dual offset prestress (pouch wrapping)
    - type: offset
      source_pid: 1
      thickness: 1.0        # outer - inner = 1.0 - (-0.2) = 1.2
      num_layers: 1

      new_pid: 12
      material_card: |
        *MAT_ELASTIC
        $#     mid        ro         e        pr
             @MID@       1.0     10000       0.3

      offset_direction: +normal

      bbox_xmax: 10.0
      connection_mode: tied
      new_pid: 15
      part_title: "Advanced_Offset_Example"
      material_card: |
        *MAT_ELASTIC
        $#     mid        ro         e        pr
             @MID@       2.0     15000       0.25

  생성 키워드:

    공통:
      *PART (새 PID, SECID, MID)
      *SECTION_SOLID / *SECTION_TSHELL / *SECTION_SHELL
      *MAT_* (material_card 지정 시)

    CZM mode 추가:
      *PART (Cohesive layer)
      *SECTION_SOLID (ELFORM=20, zero-thickness)
      *MAT_COHESIVE_* (czm_material_card)

    Contact mode 추가:
      주석으로 *CONTACT_AUTOMATIC_SURFACE_TO_SURFACE 템플릿 출력

    Dual offset prestress 추가:
      *.dynain (*INITIAL_STRESS_SOLID, 역방향 응력)

  주의사항:
    * Source 파트는 solid elements 지원 (HEX8 권장, TET4 품질 저하).
    * Shell element source는 제한적 지원 (PID tracking 문제).
      → 중간 결과를 파일 저장 후 base_model로 재로드 권장.
    * TET4 source는 degenerate HEX8 생성 (aspect ratio 999, warping 90°).
      → HEX8 source 사용 권장. WEDGE6 지원은 향후 추가 예정.
    * offset_direction=-normal은 negative Jacobian 발생 (알려진 버그).
      → ±x/±y/±z 고정 방향 사용 권장.
    * CZM mode에서 czm_material_card는 필수.
      Placeholder 값이 아니라 실제 재료 시험 값 사용 권장.
    * Dual offset prestress는 element_type=solid + E,nu 지정 필수.
      YAML에 material 섹션 또는 material_card에 *MAT_ELASTIC 지정.
    * Contact mode에서는 수동으로 *CONTACT_* 키워드 추가 필요.
    * num_layers > 1 시 각 층은 노드 공유 (node-shared stack).
      레이어별 다른 재료 사용 시 여러 offset operation 사용.
    * offset_direction=+normal 시 concave 표면에서 self-intersection 가능.
      → 고정 방향 사용 또는 region selection으로 영역 제한.
    * Element quality validation: Aspect Ratio > 20 또는 Jacobian < -1e-10 시 오류.
      Warping > 45° 경고는 Jacobian > 0이면 허용 가능.

----------------------------------------------------------------
3.7 material_card 작성법 상세
----------------------------------------------------------------

material_card는 LS-DYNA *MAT 키워드를 통째로 YAML에 기입합니다.

[기본 규칙]

  1. material_card: | 뒤에 여러 줄을 그대로 입력
     (YAML의 '|'는 literal block = 줄바꿈 보존)

  2. mid 자리에 MIDxxx 자리표시자를 사용
     예: MID001, MID002, MID099 등
     기존 모델의 MAT ID와 겹치지 않는 번호가 자동 부여됩니다.

  3. 같은 MIDxxx를 여러 layer에 쓰면 동일 MAT ID를 공유
     → *MAT 카드는 1회만 출력되고, *PART에서 같은 mid 참조

[MID 공유 예시]

  layers:
    - thickness: 0.3
      material_card: |                    # ← MID001 (Steel)
        *MAT_ELASTIC
        $#     mid        ro         e        pr
             MID001  7.85E-09  2.10E+05       0.3

    - thickness: 0.1
      material_card: |                    # ← MID002 (접착제)
        *MAT_ELASTIC
        $#     mid        ro         e        pr
             MID002  1.20E-09  3.00E+03      0.35

    - thickness: 0.3
      material_card: |                    # ← MID001 재사용 (같은 Steel)
        *MAT_ELASTIC
        $#     mid        ro         e        pr
             MID001  7.85E-09  2.10E+05       0.3

        MID002 → 실제 ID 6 (1회 출력)

        Layer 2 *PART: mid=6
        Layer 3 *PART: mid=5  ← Layer 1과 같은 재료

[LS-DYNA 10자리 고정폭 형식]

  LS-DYNA 카드는 10자리 고정폭 형식입니다.

      $#      c         p      lcss      lcsr        vp

----------------------------------------------------------------
3.19 bend 이론 상세
----------------------------------------------------------------

  이 절에서는 bend(굽힘) 변형의 수학적 기반을 상세히 설명합니다.

  ■ 1. 처짐 함수 w(x1, x2)

  굽힘 변형은 면내 좌표 (x1, x2)에서 법선 방향 처짐량 w를
  정의하는 함수로 기술됩니다.

  source별 처짐 함수 생성 방법:

    formula: 수식을 101x101 그리드에 평가
      w(x1, x2) = evaluate(expression)
      변수: x1, x2 (BB min 기준 상대좌표)
            L1, L2 (BB 크기), pi = 3.14159...

    dat: 공백 구분 2D 그리드 파일을 직접 로드
      행 0 = x2_max, 행 N-1 = x2_min (역순 y축)
      열 0 = x1_min, 열 M-1 = x1_max
      그리드 범위가 파트 BB에 자동 매핑

    dat_pair: 상/하면 처짐 쌍
      w_mid = (w_top + w_bottom) / 2   (곡률은 중면 기준)
      w_node = w_bottom*(1-t) + w_top*t (t = 두께 방향 비율)


  ■ 2. 곡률 계산 (유한차분)

  처짐 그리드에서 2차 편미분을 유한차분으로 계산합니다.
  그리드 간격을 dx1, dx2라 하면:

    kappa_11[i][j] = -(w[i][j+1] - 2*w[i][j] + w[i][j-1]) / dx1^2

    kappa_22[i][j] = -(w[i-1][j] - 2*w[i][j] + w[i+1][j]) / dx2^2

    kappa_12[i][j] = -(w[i-1][j+1] - w[i-1][j-1]
                       - w[i+1][j+1] + w[i+1][j-1]) / (4*dx1*dx2)

  부호: kappa = -d2w/dx^2 (판이론 부호 규약).

  경계 처리:
    j=0 또는 j=M-1: 편측 차분 (forward/backward difference)
    i=0 또는 i=N-1: 편측 차분

  기울기 (Kirchhoff 면내 보정용):

    dw/dx1[i][j] = (w[i][j+1] - w[i][j-1]) / (2*dx1)
    dw/dx2[i][j] = (w[i-1][j] - w[i+1][j]) / (2*dx2)

  그리드 노드에서 미리 계산 후, 임의 좌표에서는 bilinear 보간.


  ■ 3. 굽힘 변형률 (Kirchhoff 판이론)

  중립면에서 법선 방향 거리 d인 점의 변형률:

    eps_11 = -d * kappa_11
    eps_22 = -d * kappa_22
    gamma_12 = -2 * d * kappa_12

  여기서 d = n_coord - n_mid, n_mid = (n_min + n_max) / 2.

  성질:
    - 중립면(d=0): 변형률 = 0
    - 상면(d>0)과 하면(d<0): 반대 부호 → 순수 굽힘
    - 멤브레인 변형 없음 (법선 방향 변형률 eps_33 = 0)


  ■ 4. 노드 변위 (deform 모드)

  각 노드에 대해 3개 방향 변위를 적용합니다:

    Delta_n  = w(x1, x2)                 (법선 방향 처짐)
    Delta_x1 = -d * dw/dx1(x1, x2)       (Kirchhoff 면내 보정)
    Delta_x2 = -d * dw/dx2(x1, x2)       (Kirchhoff 면내 보정)

  면내 보정 (Delta_x1, Delta_x2)은 얇은 판에서는 미미하지만,
  두꺼운 파트에서 정확한 굽힘 기하형상을 위해 필요합니다.

  물리적 의미: 판이 굽혀질 때 상면은 인장, 하면은 압축되어
  면내 방향으로도 미소 변위가 발생합니다.


  ■ 5. 응력 부호 규약

    deform 모드:
      기하형상을 굽힌 후 → 역방향 응력 부여 (strain * (-1))
      DR 시 굽힌 상태를 유지하는 잔류응력 역할

    stress 모드:
      기하형상 변경 없음 → 순방향 응력 부여 (strain 그대로)
      DR 시 평면 → 굽힘 변형이 발생

    | 모드    | 기하형상 | 응력 부호 | DR 결과        |
    |---------|----------|-----------|----------------|
    | deform  | 굽힘     | 역방향    | 굽힌 상태 유지 |
    | stress  | 평면     | 순방향    | 굽힘 변형 발생 |

  응력 계산 순서: 반드시 변위 적용 전에 수행.
  변위 후에는 centroid z좌표가 이동하여 d 계산이 부정확.


  ■ 6. Hooke's law (등방 탄성체)

  bend와 indent 공통으로 사용하는 응력-변형률 관계:

    Lame 파라미터:
      lambda = E * nu / ((1+nu)*(1-2*nu))
      mu = E / (2*(1+nu))

    응력:
      sig_ij = lambda * tr(eps) * delta_ij + 2*mu*eps_ij

    여기서 tr(eps) = eps_11 + eps_22 + eps_33.
    평면 굽힘에서 eps_33 = 0이므로:
      tr(eps) = eps_11 + eps_22

    구체적으로:
      sig_11 = lambda*(eps_11+eps_22) + 2*mu*eps_11
      sig_22 = lambda*(eps_11+eps_22) + 2*mu*eps_22
      sig_33 = lambda*(eps_11+eps_22)
      sig_12 = 2*mu*eps_12


  ■ 7. 수치 검증 예

  2x2x2 블록, formula: "0.5*sin(pi*x1/L1)*sin(pi*x2/L2)"
  E=210000, nu=0.3

  중심(x1=L1/2, x2=L2/2)에서:
    w = 0.5 * sin(pi/2) * sin(pi/2) = 0.5

    kappa_11 = (pi/L1)^2 * 0.5 * sin(pi/2) * sin(pi/2)
    kappa_22 = (pi/L2)^2 * 0.5 * sin(pi/2) * sin(pi/2)

  상면 요소(d=0.5):
    eps_11 = -0.5 * kappa_11
    sig = Hooke's law 적용

  deform 모드 → 역방향 → DR 시 0.5mm 처짐 형상 유지.

----------------------------------------------------------------
3.20 indent 이론 상세
----------------------------------------------------------------

  이 절에서는 indent/emboss 변형의 수학적 기반을 상세히 설명합니다.

  ■ 1. Signed Distance Field (부호 거리장)

  indent 형상은 닫힌 루프(closed loop)로 정의되며, 메쉬의 각
  노드에서 이 루프까지의 signed distance d를 계산하여 영역을
  분류합니다.

    d < 0          : 루프 안쪽 → flat indent (전체 깊이 적용)
    0 <= d < r1    : r1 구간  → 하부 arc (급경사)
    r1 <= d < r1+r2: r2 구간  → 상부 arc (완경사)
    d >= r1+r2     : 루프 바깥 → 변위 없음

  부호 규약: 안쪽 = 음수, 바깥 = 양수.

  (i) 최소 거리 계산
    루프의 각 세그먼트 (A, B)에 대해 점 P의 최근접점:

      t = clamp( dot(P-A, B-A) / |B-A|^2,  0,  1 )
      closest = A + t * (B-A)
      dist = |P - closest|

    모든 세그먼트 중 최솟값이 부호 없는 거리.

  (ii) 내부/외부 판별: Winding Number

    단순 cross-product 부호는 오목(concave) 다각형에서 오류.
    Winding Number는 어떤 형상에서도 정확합니다:

      wn = 0
      for each segment (A, B):
          if A.y <= P.y:
              if B.y > P.y:
                  if cross(B-A, P-A) > 0: wn++
          else:
              if B.y <= P.y:
                  if cross(B-A, P-A) < 0: wn--

      inside = (wn != 0)
      signed_distance = inside ? -min_dist : +min_dist

  (iii) 그래디언트 방향 (응력 계산용)

    최근접 경계점 C에서 쿼리점 P 방향의 단위 벡터:

      gradient = (P - C) / |P - C|     (|P-C| > 0일 때)

    이 벡터는 필렛 곡률의 방향을 나타내며, 응력 텐서 분해에 사용.


  ■ 2. Quarter-Arc 프로파일 함수 h(d)

  두 개의 1/4 원호(또는 1/4 타원)로 바닥 평면과 원래 표면을
  매끄럽게 연결합니다. 금형의 펀치 필렛(r1)과 다이 필렛(r2)에
  대응합니다.

  스케일링 팩터:

      k = depth / (r1 + r2)

      k = 1  : 정확한 1/4 원호 (depth = r1+r2)
      k < 1  : 1/4 타원 (depth < r1+r2, 완만한 전이)
      k > 1  : 급경사 타원 (depth > r1+r2, 경고)

  단면도:

      r2 zone (완만)    r1 zone (급경사)   flat   r1 zone     r2 zone
    z=0  ━━━━━╲                                          ╱━━━━━━
              ╲  r2 arc                         r2 arc  ╱
               ╲                                       ╱
                |  ← d=r1 접합점                      |
               ╱                                       ╲
              ╱   r1 arc                        r1 arc  ╲
    z=-d ━━━╱━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━╲━━━

  (i) r1 구간: d in [0, r1]  — 하부 arc (바닥 → 접합점)

      t = d / r1

      h(d) = -depth + k * r1 * (1 - sqrt(1 - t^2))

    검증:
      h(0) = -depth                              (바닥에서 연속)
      h(r1) = -depth + k*r1 = -depth*r2/(r1+r2)  (접합점)
      h'(0) = 0                                  (수평 접선)
      h'(r1) -> infinity                         (수직 접선)

  (ii) r2 구간: d in [r1, r1+r2]  — 상부 arc (접합점 → 표면)

      u = (r1 + r2 - d) / r2

      h(d) = -k * r2 * (1 - sqrt(1 - u^2))

    검증:
      h(r1) = -k*r2 = -depth*r2/(r1+r2)          (접합점, r1과 일치)
      h(r1+r2) = 0                                (원래 표면)
      h'(r1) -> infinity                          (수직 접선)
      h'(r1+r2) = 0                               (수평 접선)

  (iii) 전체 요약

      d < 0          :  h = -depth
      d in [0, r1]   :  h = -depth + k*r1*(1 - sqrt(1 - (d/r1)^2))
      d in [r1, R]   :  h = -k*r2*(1 - sqrt(1 - ((R-d)/r2)^2))
      d >= R         :  h = 0

    여기서 R = r1 + r2.

  프로파일 특성:
    - C^0 연속: 접합점(d=r1)에서 높이 일치 + 양쪽 수직 접선 방향 일치
    - 수평 접선: d=0 (바닥)과 d=R (표면)에서 h'=0
    - 비대칭: r1 < r2이면 하부 급경사 + 상부 완만 (일반적 스탬핑 필렛)
    - 양각(emboss): depth < 0 → h(d) > 0 (표면을 바깥으로 당김)
      수식 그대로 유효 (k < 0, 결과가 정확히 반전)


  ■ 3. 두께 관통 보간 (Through-Thickness)

  indent 면(표면)의 변위를 두께 방향으로 선형 보간합니다.

    t_frac = (n - n_min) / (n_max - n_min)

    여기서 n = 노드의 법선축 좌표, n_min/n_max = 파트 BB.
    direction=-z 시: t_frac=1 (상면), t_frac=0 (하면).

    displacement = h_surface * [bottom_ratio + (1 - bottom_ratio) * t_frac]

    bottom_ratio = 0.0 (기본): 상면만 이동, 하면 고정 → 두께 변화
    bottom_ratio = 1.0: 전체 관통 (리지드 이동) → 두께 보존
    bottom_ratio = 0.5: 하면이 표면의 50% 이동

  가정: 파트가 extrude 형상 (두께 방향 일정). 곡면 파트에서는
  BB 기반 t_frac이 근사적입니다.


  ■ 4. 프로파일 곡률 h''(d) (2차 도함수)

  stress: true 시 필렛 영역의 굽힘 응력 계산에 사용됩니다.
  h(d)를 d에 대해 두 번 미분한 해석적 공식입니다.

  (i) r1 구간: d in [0, r1]

      h'(d) = k * d / (r1 * sqrt(1 - (d/r1)^2))

      h''(d) = k / (r1 * (1 - t^2)^(3/2))       (t = d/r1)

    특성:
      h''(0) = k / r1                             (최소 곡률)
      h''(r1) -> infinity                         (접합점 특이점)

  (ii) r2 구간: d in [r1, r1+r2]

      h''(d) = -k / (r2 * (1 - u^2)^(3/2))       (u = (R-d)/r2)

    특성:
      h''(r1) -> -infinity                        (접합점, 반대 부호)
      h''(R) = -k / r2                            (표면 근처 최소 곡률)

  (iii) 곡률 특이점(singularity) 처리

    d = r1 (r1/r2 접합점)에서 h'' -> +/-infinity.
    실제 계산에서는 곡률을 제한하여 변형률이 물리적 한계를
    초과하지 않도록 합니다:

      strainLimit = 0.05   (5%)
      thickness = n_max - n_min
      h''_max = strainLimit / (thickness / 2)

    변형률 eps = d_neutral * h''에서 d_neutral = thickness/2일 때
    eps = 0.05가 최대값이 됩니다.


  ■ 5. 굽힘 응력 계산 (Kirchhoff 판이론)

  indent 필렛의 곡률에서 Kirchhoff 판이론 기반 굽힘 응력을
  계산하는 전체 과정입니다.

  (i) 그래디언트 방향 분해

    필렛 곡률 h''(d)는 스칼라(1차원 값)이지만, 실제 면내
    곡률은 2차원 텐서입니다. 그래디언트 방향 (gx, gy)로
    분해합니다:

      kappa_11 = -h''(d) * gx^2       (x방향 곡률)
      kappa_22 = -h''(d) * gy^2       (y방향 곡률)
      kappa_12 = -h''(d) * gx * gy    (비틀림 곡률)

    여기서 (gx, gy) = 최근접 경계점 → 노드 방향의 단위벡터.
    부호: kappa = -h''(d) (판이론 부호 규약, kappa = -d2w/dx^2).

    예시: 순수 y방향 그래디언트 (gx=0, gy=1)
      → kappa_11 = 0, kappa_22 = -h'', kappa_12 = 0
    대각선 그래디언트 (gx=gy=1/sqrt(2))
      → kappa_11 = kappa_22 = -h''/2, kappa_12 = -h''/2

  (ii) 굽힘 변형률 (판 이론)

    중립면에서 거리 d_n인 점의 변형률:

      eps_11 = -d_n * kappa_11
      eps_22 = -d_n * kappa_22
      gamma_12 = -2 * d_n * kappa_12

    여기서 d_n = n_coord - n_mid (법선축 좌표 - 중립면 좌표).
    n_mid = (n_min + n_max) / 2.

    상면 (d_n > 0)과 하면 (d_n < 0)에서 부호가 반대
    → 판의 위아래에서 반대 방향 응력 (순수 굽힘).

  (iii) 면내 좌표 → 전체 좌표 매핑

    plane=xy일 때: eps_xx = eps_11, eps_yy = eps_22, eps_xy = gamma_12/2
    plane=yz일 때: eps_yy = eps_11, eps_zz = eps_22, eps_yz = gamma_12/2
    plane=zx일 때: eps_zz = eps_11, eps_xx = eps_22, eps_zx = gamma_12/2

    법선 방향(예: eps_zz for plane=xy)은 0.

  (iv) Hooke's law (등방 탄성체)

    Lame 파라미터:
      lambda = E * nu / ((1 + nu) * (1 - 2*nu))
      mu = E / (2 * (1 + nu))

    응력 텐서:
      sig_ij = lambda * (eps_11 + eps_22 + eps_33) * delta_ij
               + 2 * mu * eps_ij

    구체적으로 (plane=xy, eps_zz=0):
      sig_xx = lambda * (eps_xx + eps_yy) + 2*mu*eps_xx
      sig_yy = lambda * (eps_xx + eps_yy) + 2*mu*eps_yy
      sig_zz = lambda * (eps_xx + eps_yy)
      sig_xy = 2 * mu * eps_xy

    수치 예 (E=210000, nu=0.3):
      lambda = 210000*0.3 / (1.3*0.4) = 121154
      mu = 210000 / 2.6 = 80769

      순수 y방향 그래디언트, 곡률 cap 적용 (h''=0.05):
      eps_yy = -0.5 * (-0.05) = 0.025 (상면, d_n=0.5)
      → 역방향: eps_yy = -0.025
      sig_yy = 121154*(-0.025) + 2*80769*(-0.025) = -3029 + -4038 = -7067
      sig_xx = sig_zz = 121154*(-0.025) = -3029

  (v) 응력 부호 규약

    indent는 deform(변형) 모드만 지원합니다:
    기하형상이 indent된 상태에서 역방향 응력을 부여합니다.

      reverse_strain = strain * (-1)
      stress = fromStrain(reverse_strain, E, nu)

    DR(Dynamic Relaxation) 해석 시 이 역방향 응력이
    indent 이전 형상으로 돌아가려는 복원력으로 작용하여,
    indent 형상이 유지됩니다.

    *참고: 응력 계산은 반드시 노드 변위 적용 전에 수행.
    변위 후에는 요소 centroid의 z좌표가 이동하여
    d_n (중립면 거리) 계산이 부정확해집니다.


  ■ 6. 응력 병합 (다중 operation)

  같은 요소에 여러 operation (squeeze + indent, bend + indent 등)
  이 적용되면, 각 operation의 응력이 dynain 출력 전에 합산됩니다:

    merged[elementId].stress += operation_stress

  writeOutput()에서 element ID별로 std::map에 누적하여
  요소당 하나의 *INITIAL_STRESS_SOLID 항목으로 출력합니다.


  ■ 7. Catmull-Rom 폐곡선 (Spline 형상)

  shape: spline 시 제어점을 Catmull-Rom 스플라인으로 보간합니다.

  N개 제어점 P_0, P_1, ..., P_{N-1} (폐곡선: P_N = P_0):

    각 세그먼트 i에서 t in [0, 1]:

      P(t) = 0.5 * [ (2*P_1)
                    + (-P_0 + P_2) * t
                    + (2*P_0 - 5*P_1 + 4*P_2 - P_3) * t^2
                    + (-P_0 + 3*P_1 - 3*P_2 + P_3) * t^3 ]

    여기서 P_0 = P_{i-1}, P_1 = P_i, P_2 = P_{i+1}, P_3 = P_{i+2}
    (인덱스는 mod N으로 순환).

  세그먼트당 20개 샘플로 이산화 → 직선 세그먼트 배열로 변환.
  이후 signed distance 계산은 polygon과 동일한 로직을 재사용.


  ■ 8. 성능 최적화: AABB 사전 필터

    1) Loop의 bounding box + (r1+r2) 여유 → affected_bbox
    2) affected_bbox 밖의 노드 → 즉시 skip (d >= r1+r2 보장)
    3) 나머지 노드만 정밀 signed distance 계산

  10,000 요소 모델에서 약 70-90% 노드를 skip.
  처리 시간: 200 요소 ~4ms, 800 요소 ~17ms, 10,000 요소 ~150ms.


  ■ 9. 수치 검증 예

  10x10x2 블록 (1mm 간격), [3,3]-[7,7] 사각형 indent:
  depth=0.5, r1=0.5, r2=1.0

    k = 0.5 / (0.5 + 1.0) = 1/3

  상면(z=2) 노드 검증:
    (5, 5): d < 0 (루프 안쪽) → z = 2 - 0.5 = 1.500
    (2.5, 5): d = 0.5 (r1 경계) → h = -0.5 + (1/3)*0.5*1 = -0.333
              → z = 2 - 0.333 = 1.667
    (2, 5): d = 1.0 → u = 0.5/1.0 = 0.5
              h = -(1/3)*1.0*(1 - sqrt(1-0.25)) = -0.333*(1-0.866) = -0.045
              → z = 2 - 0.045 = 1.955
    (1.5, 5): d = 1.5 = r1+r2 → h = 0 → z = 2.000 (변경 없음)

  중간면(z=1): 상면의 50% 변위 (t_frac = 0.5)
  하면(z=0): 변위 없음 (bottom_ratio = 0)

  양각(depth=-0.5) 검증:
    k = -0.5 / 1.5 = -1/3
    (5, 5): h = -(-0.5) = 0.5 → z = 2 + 0.5 = 2.500
    indent와 정확히 반대 (음각 z + 양각 z = 2 * 원래 z)

================================================================
3.22 disconnect 이론 상세
================================================================

----------------------------------------------------------------
노드 분리 (Decohesion / Node Splitting) 개요
----------------------------------------------------------------

Conformal 메쉬에서 인접 요소들은 노드를 공유합니다.
"disconnect"는 이 공유 노드를 복제하여 요소 간 연결을 끊는 작업입니다.

목적별 3가지 모드:

  [full mode] - Peridynamics / Bond-based PD
    모든 요소의 모든 노드를 독립적으로 복제합니다.
    N개 요소 × M 노드 = N×M개 신규 노드가 생성됩니다.
    HEX8(M=8), TET4(M=4).
    *SECTION_SOLID_PERI (ELFORM=48, DR=1.01, PTYPE=1) 자동 생성.
    Peridynamic 해석에서 본드 기반 상호작용이 가능하도록 합니다.

  [czm mode] - Cohesive Zone Model (층간 분리)
    파트 간 공유 면(inter-part face)의 노드만 선택적으로 분리합니다.
    같은 파트 내 연결은 유지됩니다 (intra-part 면 보존).
    분리된 계면에 cohesive 요소를 삽입합니다.

    알고리즘:
    1. Face adjacency 구축
       HEX8: sorted(n1,n2,n3,n4) → FaceKey (6면 × 요소)
       TET4: sorted(n1,n2,n3,n3) → FaceKey (4면 × 요소)
       QUAD4 셸: sorted(n1,n2,n3,n4) → FaceKey (coincident 면)

    2. Inter-part face 식별
       공유 면 양쪽의 partId가 다른 면 → 계면

    3. 계면 노드 복제
       Primary PID (최소 PID): 원본 노드 유지
       Secondary PID (나머지): 동일 위치에 신규 노드 생성
       (같은 파트의 여러 요소는 동일 복제 노드 공유)

    4. Cohesive 요소 생성 (8-node solid, ELFORM=19)
       Bottom face (primary PID): 원본 노드
       Top face (secondary PID): 복제 노드
       계면 형상: QUAD face → ELFORM=19, TRI face → 퇴화 hexahedron

    5. 재료/섹션/파트 키워드 자동 생성
       *MAT_COHESIVE_MIXED_MODE (MAT 138)
       *SECTION_SOLID (ELFORM=19)
       *PART (Cohesive interface)

  [mefem mode] - Mixed Explicit FEM (Tied + Failure)
    czm과 동일한 선택적 노드 분리 + tied 구속 + 파괴 조건.

    알고리즘:
    1~3. czm과 동일한 노드 분리
    4. 동일 위치 노드 쌍을 *SET_NODE_LIST로 묶음
    5. 각 셋에 *CONSTRAINED_TIED_NODES_FAILURE 적용
       EPPF = failure_strain (파괴 소성변형률)
       ETYPE = 1 (solid)

----------------------------------------------------------------
restack + disconnect czm 파이프라인
----------------------------------------------------------------

복합 적층 구조의 층간 분리 해석에서 표준 워크플로우:

  1. restack: 균일 extrude 메쉬를 레이어별로 서로 다른 파트로 분할
             각 층에 다른 재료 물성 부여 가능
  2. disconnect czm: 파트 간 계면(inter-part face)에 cohesive 요소 삽입
                    층간 분리(delamination) 해석 가능

  단순화 단계:
    - 원하는 층 수만큼 restack layers 정의
    - disconnect czm 한 줄 추가
    - N개 레이어 → (N-1)개 cohesive 계면 자동 생성

  예 (3층 적층 → 2개 계면):
    restack: PID1(원본) → PID2(층1), PID3(층2), PID4(층3)
    disconnect czm:
      PID2-PID3 계면 → cohesive 1
      PID3-PID4 계면 → cohesive 2
      PID5: Cohesive interface part (자동)

----------------------------------------------------------------
Cohesive 재료 물성 설명 (*MAT_COHESIVE_MIXED_MODE = MAT 138)
----------------------------------------------------------------

  생성된 placeholder 값:

  *MAT_COHESIVE_MIXED_MODE
  $#     mid    ro  roflg intfail   en      et     gic   giic
       ID   0.0   0    0.0  1.0E6  1.0E6   1.0    2.0
  $#   xmu    t     s    und   utd  gamma
       1.0 50.0  30.0   0.0   0.0    1.0

  파라미터 의미:
    EN     : 법선 방향 강성 (접착층 탄성계수/두께)
    ET     : 전단 방향 강성
    GIC    : Mode-I 임계 에너지 해방률 (법선 박리)
    GIIC   : Mode-II 임계 에너지 해방률 (전단 박리)
    T      : 법선 인장 강도
    S      : 전단 강도
    XMU    : 혼합 모드 파괴 지수 (일반적으로 1.0~2.0)
    GAMMA  : 혼합 모드 파라미터

  주의: 위 값은 초기값이며 반드시 실제 재료 시험 데이터로 교체 필요.

================================================================
3.24 restack 이론 상세
================================================================

----------------------------------------------------------------
개요
----------------------------------------------------------------

restack은 단일 파트의 extrude(압출) 메쉬를 여러 레이어(층)로
재분류하여 각 층에 서로 다른 재료 물성을 부여합니다.

----------------------------------------------------------------
알고리즘
----------------------------------------------------------------

1. Extrusion 축 감지 (direction: auto)

   대상 파트의 모든 노드를 X, Y, Z 각 축 방향으로 정렬.
   분산(variance)이 가장 작은 축 = extrusion 방향.
   (extrude 메쉬는 압출 방향에서 균일한 간격을 가짐)

   예: Z방향 압출 → Z 분산이 X,Y에 비해 균일

2. 노드 컬럼(column) 구성

   각 노드를 압출 축에 수직인 2D 좌표 (u, v)로 투영.
   같은 (u, v) 위치의 노드들을 하나의 컬럼으로 묶음.
   컬럼 내 노드를 축 좌표 기준으로 정렬.

   컬럼 수 = 단면의 노드 수
   컬럼 길이 = extrusion 방향 노드 수

3. 레이어 경계 결정

   원래 두께 = 컬럼 전체 길이 (축 좌표 max - min)
   각 레이어 두께 = yaml의 layers[i].thickness 비율로 균등 분할
   (두께 불일치 시 내부적으로 비율 조정)

4. 요소 레이어 할당

   각 요소의 중심 Z(또는 X/Y) 좌표로 해당 레이어 결정.
   레이어 → 새 PID 할당 (maxPartId+1, maxPartId+2, ...)

5. 출력 생성

   원본 요소: removedElementIds_ 추가
   새 요소: 동일 nodeIds + 새 PID → addedElements_
   각 레이어별 *PART, *SECTION_SOLID, *MAT_* 키워드 추가

----------------------------------------------------------------
layers 두께 매칭
----------------------------------------------------------------

원본 두께와 layers 합이 다를 때 (두께 불일치):

  원본 두께: T_orig = Z_max - Z_min
  layers 두께: T_sum = Σ layers[i].thickness

  비율: scale = T_orig / T_sum
  실제 레이어 두께: t_i = layers[i].thickness × scale

  ※ layers 수 ≠ 요소 층 수일 때 요소를 비율로 할당.

----------------------------------------------------------------
element_type 옵션
----------------------------------------------------------------

  solid  (기본): HEX8 → HEX8, TET4 → TET4 (PID만 변경)
  shell:         QUAD4 → QUAD4 (PID만 변경)
  tshell:        HEX8 → TSHELL (ELEMENT_TSHELL 섹션으로 출력)


================================================================
3.25 formstrain 이론 상세
================================================================

----------------------------------------------------------------
개요
----------------------------------------------------------------

성형 공정(벤딩, 롤포밍 등)에서 최종 형상의 잔류 소성 변형률을
셸 메쉬의 기하학적 곡률로부터 역산합니다.

출력: *INITIAL_STRESS_SHELL 형태의 dynain 초기응력.
      EPS(유효 소성 변형률)만 사용 (응력 성분은 0).

----------------------------------------------------------------
알고리즘
----------------------------------------------------------------

Step 1. 엣지 인접 맵 구성

  모든 셸 요소에 대해 엣지(2-node key) → [인접 요소 ID] 맵 생성.
  내부 엣지: 인접 요소 2개 (공유 엣지)
  경계 엣지: 인접 요소 1개 (무시)

Step 2. 이면각(Dihedral Angle) 계산

  각 내부 공유 엣지에 대해 양쪽 요소의 법선벡터 NA, NB 계산.

  cosθ = NA · NB     (내적, 수치 클램핑 [-1, 1])
  θ = arccos(cosθ)   (이면각, 단위: radian)

  ※ cosθ < -0.5이면 법선 방향 불일치로 해당 엣지 무시.

Step 3. 곡률 추정

  L = |centroid_A - centroid_B|   (두 요소 중심간 거리)

  κ = θ / L    [rad/mm 또는 rad/inch]

  각 요소는 인접 모든 엣지에서의 κ 중 최대값을 사용.
  (min_curvature 미만은 필터링)

Step 4. 굽힘 변형률 → 소성 변형률

  ε_bend = κ × t/2    (표면 굽힘 변형률, t = 셸 두께)

  ε_yield = σ_y / E   (항복 변형률, σ_y = MAT_024 yield stress)

  EPS = max(0, ε_bend - ε_yield)    (소성 변형률)

  ※ EPS = 0이면 해당 요소는 출력하지 않음.
  ※ 같은 요소가 여러 인접 엣지를 가질 때 max() 병합.

Step 5. *INITIAL_STRESS_SHELL 출력

  NPLANE = 1 (적분점 1개)
  NTHICK = 2 (두께 방향 2점: T = -1.0, +1.0)
  각 적분점: sigxx=sigyy=sigzz=sigxy=sigyz=sigxz=0.0, EPS=계산값

----------------------------------------------------------------
수식 요약
----------------------------------------------------------------

  κ = arccos(n_A · n_B) / |c_A - c_B|
  ε = κ × t/2
  EPS = max(0, ε - σ_y/E)

----------------------------------------------------------------
재료 물성 조회 경로
----------------------------------------------------------------

  *MAT_024 (PIECEWISE_LINEAR_PLASTICITY)
   → Card 1, Field 5: SIGY (초기 항복응력)

  *MAT_024가 없거나 SIGY=0이면 해당 파트 처리 건너뜀.

  shell_thickness 우선순위:
    YAML 지정값 > *SECTION_SHELL T1 > 처리 불가


================================================================
3.26 quadratic 변환 이론 상세 (tet10/hex20/quad8/tria6)
================================================================

----------------------------------------------------------------
개요
----------------------------------------------------------------

1차(linear) 요소를 2차(quadratic) 요소로 변환합니다.
각 엣지의 중점에 새 노드를 생성하고 connectivity를 확장합니다.

----------------------------------------------------------------
변환 종류
----------------------------------------------------------------

  ┌──────────────┬─────────────┬─────────┬───────────────────────┐
  │ operation    │ 변환        │ 신규노드 │ 기본 ELFORM           │
  ├──────────────┼─────────────┼─────────┼───────────────────────┤
  │ tet10        │ TET4 → TET10│ 6 (엣지)│ 17                    │
  │ hex20        │ HEX8 → HEX20│ 12 (엣지)│ 23                   │
  │ quad8        │ QUAD4→ QUAD8│ 4 (엣지)│ 23                    │
  │ tria6        │ TRIA3→ TRIA6│ 3 (엣지)│ 24                    │
  └──────────────┴─────────────┴─────────┴───────────────────────┘

----------------------------------------------------------------
알고리즘
----------------------------------------------------------------

Step 1. 엣지 중점 노드 생성

  각 요소의 모든 엣지에 대해:
    key = sorted(nA, nB)  (정렬된 노드쌍)
    중점 위치 = (pos_A + pos_B) / 2

  edgeMidNodeMap_[key] → midNodeId (operation 간 공유, 중복 없음)

  ※ 인접 요소가 같은 엣지를 공유하면 동일 중점 노드 사용.

Step 2. 2차 connectivity 구성

  TET10 (4 corner + 6 edge):
    n1-n4: 원본 코너 노드
    n5: midpoint(n1,n2)
    n6: midpoint(n2,n3)
    n7: midpoint(n1,n3)
    n8: midpoint(n1,n4)
    n9: midpoint(n2,n4)
    n10: midpoint(n3,n4)

  HEX20 (8 corner + 12 edge):
    n1-n8: 원본 코너 노드
    n9-n20: 12개 엣지 중점 (LS-DYNA HEX20 순서에 따름)

  QUAD8 (4 corner + 4 edge):
    n1-n4: 원본 코너 노드
    n5: midpoint(n1,n2), n6: midpoint(n2,n3)
    n7: midpoint(n3,n4), n8: midpoint(n4,n1)

  TRIA6 (3 corner + 3 edge):
    n1-n3: 원본 코너 노드
    n4: midpoint(n1,n2), n5: midpoint(n2,n3), n6: midpoint(n1,n3)

Step 3. ELFORM 변경

  *SECTION_SOLID 또는 *SECTION_SHELL의 ELFORM 값을
  대상 2차 ELFORM으로 교체.

Step 4. 출력

  원본 요소 → 기존 *ELEMENT_SOLID/*ELEMENT_SHELL 줄 대체
  (2차 요소는 multi-line 형식)

----------------------------------------------------------------
다운그레이드 (elform 통합 시)
----------------------------------------------------------------

  2차 → 1차 다운그레이드 (예: TET10 → TET4):
    - 코너 노드(n1-n4)만 사용
    - mid-edge 노드는 *NODE에 남지만 참조되지 않음
    - ELFORM 값도 1차 값으로 변경


================================================================
3.27 refine 이론 상세 (요소 세분화)
================================================================

----------------------------------------------------------------
개요
----------------------------------------------------------------

대상 파트의 요소를 1:ratio³ 개수로 세분화합니다.
엣지/면/체심을 분할하여 서브 요소를 생성합니다.

----------------------------------------------------------------
ratio: 2 — 엣지 이등분
----------------------------------------------------------------

  QUAD4 1:2 → 4 sub-QUAD4
  ┌─────────────────────┐
  │  각 엣지의 중점      │
  │  + 면 중심           │
  │  → 4 sub-quad        │
  └─────────────────────┘

  노드 수: 4 corner + 4 edge midpoints + 1 face center = 9
  요소 수: 1 → 4

  TRIA3 1:2 → 4 sub-TRIA3
    3 edge midpoints → 4 sub-triangles (regular subdivision)
    노드 수: 3 corner + 3 midpoints = 6

  TET4 1:2 → 8 sub-TET4 (Bey subdivision)
    6 edge midpoints 생성.
    4 corner tets + 4 inner tets (엣지 중점 연결)
    노드 수: 4 corner + 6 midpoints = 10

  HEX8 1:2 → 8 sub-HEX8
    12 edge midpoints + 6 face centers + 1 body center = 19 신규 노드
    총 27 = 3³ 격자 노드
    노드 수: 8 corner + 12 edge + 6 face + 1 body = 27
    요소 수: 1 → 8

----------------------------------------------------------------
ratio: 3 — 엣지 삼등분
----------------------------------------------------------------

  QUAD4 1:3 → 9 sub-QUAD4
    각 엣지: 2개 삼등분점
    면 내부: 4개 내부점
    총 8 엣지점 + 4 내부점 = 12 신규 노드 (per element)

  TRIA3 1:3 → 9 sub-TRIA3
    각 엣지: 2개 삼등분점 (6개)
    면 중심: 1개
    총 7 신규 노드 (per element)

  HEX8 1:3 → 27 sub-HEX8
    각 엣지: 2개 삼등분점 (24개)
    각 면 내부: 4개 점 (24개)
    체 내부: 8개 점
    총 4³ = 64 노드 격자
    요소 수: 1 → 27

  TET4 1:3 → 미지원

----------------------------------------------------------------
노드 공유 (deduplication)
----------------------------------------------------------------

  인접 요소가 엣지/면을 공유할 때 노드 중복 방지:

  ratio:2
    edgeMidNodeMap_[sorted(nA,nB)] → midNodeId
    faceCenterNodeMap_[sorted(n1,n2,n3,n4)] → centerNodeId

  ratio:3
    edgeThirdNodeMap_[(sorted(nA,nB), idx)] → nodeId
    (idx=0: A쪽 1/3점, idx=1: B쪽 2/3점)

    면 내부점: canonical bilinear 정렬 기반 (s,t) 매핑으로
    인접 요소 간 동일한 좌표 순서 보장

----------------------------------------------------------------
TET4 저장 형식
----------------------------------------------------------------

  TET4는 내부적으로 degenerate HEX8로 저장:
    n5 = n6 = n7 = n8 = n4 (4번째 노드 반복)
  이는 LS-DYNA의 ELFORM=10/13/60 TET4 입력 형식과 동일.

4. shellmap - 쉘 기반 솔리드 매핑
================================================================

용도:
  평면에서 작성한 HEX8 디테일 메쉬를 QUAD4 쉘 표면 형상에
  맞춰 매핑합니다.

사용법:
  KooRemapper shellmap <bent_shell.k> <flat_detail.k> <output.k>
    [--thickness <값>]

인자:

옵션:
  --thickness      두께 지정 (미지정 시 flat 메쉬 Z범위에서 자동 감지)

동작:
  1) 쉘 메쉬를 edge-length 보존하며 평면 전개
  2) 디테일 메쉬의 XY좌표를 전개면에 매핑
  3) Z좌표를 쉘 표면 법선 방향 두께 오프셋으로 변환
  4) 매핑된 솔리드 메쉬 출력

3.28 IGA (Isogeometric Analysis) 이론 상세
================================================================

개요:
  IGA는 FEM의 노드 기반 보간 대신 B-Spline/NURBS를 기저 함수로 사용하는
  해석 방법입니다. 동일한 함수로 형상과 해석장을 표현하므로 형상 표현 오차가
  없고, 고차 연속성(C^(p-1))으로 더 정확한 해를 얻을 수 있습니다.

1. trivariate B-Spline NURBS box
  IGA solid는 3D 파라메트릭 공간 (r, s, t) ∈ [0,1]³에 정의된 NURBS로
  물리 공간 (x, y, z)를 매핑합니다:

    x(r,s,t) = Σ N_i(r,s,t) · P_i · w_i / Σ N_i(r,s,t) · w_i

  여기서:
    N_i(r,s,t) = B-Spline 기저 함수 (차수 p)
    P_i        = 제어점 좌표
    w_i        = 가중치 (여기서는 모두 1.0, 즉 B-Spline)

2. KooRemapper IGA box 구성
  각 파트에 대해 *IGA_3D_NURBS_XYZ로 직육면체 박스를 정의:

    - 2×2×2 knot spans (nr=ns=nt=2): 최소한의 박스
    - polynomial order p=1 (기본): 선형 NURBS (= trilinear hex)
    - h-refinement (*IGA_REFINE_SOLID rtyp=2, hrtyp=2):
      rr/rs/rt 크기로 subdivide → element edge length ≈ element_size

  8개 제어점 = 확장된 bbox 꼭짓점:
    rxminn = xmin - rr,  rxmaxx = xmax + rr
    ryminn = ymin - rs,  rymaxx = ymax + rs
    rzminn = zmin - rt,  rzmaxx = zmax + rt

  bbox 확장 목적: 경계 요소가 FE solid 표면 바깥에 위치해 임베딩이
  안정적으로 이루어지고 time-step 크기를 키울 수 있습니다.

3. TETMSH=-1 임베딩 (IGA_DEV_VOLUME_XYZ)
  *IGA_DEV_VOLUME_XYZ에 TETMSH=-1을 설정하면 LS-DYNA가 지정된
  FE solid PID(fepid)의 tetrahedral mesh를 IGA volume에 자동 임베딩합니다.
  FE mesh는 원본 그대로 유지되고, IGA가 FE의 자유도를 제어합니다.

4. LCP stabilization (*IGA_DEV_STABILIZATION)
  Light Control Point(LCP)란 물리 공간에 지지 영역이 작은 NURBS 기저.
  styp=4, tollg=1e-3 설정이 일반적으로 안정적입니다.
  불안정 시 tollg를 0.01~0.1로 증가시키십시오.

5. h-refinement 파라미터 (IGA_REFINE_SOLID)
  rtyp=2 (h-refinement), hrtyp=2 (uniform):
    itr = round(Lx / (2·rr))   (KooRemapper는 LS-DYNA 자동 계산에 맡김)
    * itr=its=itt=2 설정 → LS-DYNA가 rr/rs/rt 기준으로 세분화

6. 재료 ID 분리 원칙
  IGA 파트의 *MAT_*은 반드시 비-IGA 파트의 MID와 달라야 합니다.
  LS-DYNA는 MID를 통해 재료 유형을 판단하므로, 동일 MID를 공유하면
  IGA 파트와 FE 파트 간에 재료 해석 충돌이 발생합니다.
  KooRemapper는 applyIGA() 호출 시 ++maxMaterialId_로 새 MID를 자동 발급하고
  원본 재료 카드를 IGA .k 파일에 복사(MID만 치환)합니다.


================================================================
3.29 Offset 이론 상세
================================================================

----------------------------------------------------------------
개요: Surface Offset 및 Extrusion
----------------------------------------------------------------

Offset operation은 대상 파트의 외부 표면에서 일정 거리 떨어진 위치에
새로운 레이어를 생성합니다. Extrusion 방향과 요소 타입, 연결 방식을
제어하여 다양한 물리 현상을 모델링할 수 있습니다.

주요 응용:
  1. Battery pouch wrapping: 내부 압축 + 외부 릴랙스 prestress
  2. Thermal insulation: 단열재 레이어 추가
  3. Coating/Cladding: 표면 코팅 또는 클래딩
  4. Multi-layer stack: 연속 offset으로 복합 구조 생성
  5. Delamination analysis: CZM 연결로 층간 분리 해석

----------------------------------------------------------------
1. 표면 추출 (Surface Extraction)
----------------------------------------------------------------

Solid 요소(HEX8, TET4)의 외부 표면을 자동 감지합니다.

알고리즘:
  1. 각 요소의 모든 면(face)을 순회
     - HEX8: 6개 면 (각 4개 노드)
     - TET4: 4개 면 (각 3개 노드)

  2. 면 키(face key) 생성
     - 면을 구성하는 노드 ID를 정렬하여 고유 키 생성
     - 예: [N3, N1, N4, N2] → [N1, N2, N3, N4]

  3. 면 출현 횟수 카운트
     - 내부 공유 면: 2회 출현 (인접 요소 2개가 공유)
     - 외부 표면 면: 1회 출현 (한쪽만 요소 존재)

  4. 출현 횟수 = 1인 면을 표면으로 수집
     - 각 면을 ShellElement로 변환 (QUAD4 또는 TRIA3)

결과: std::vector<ShellElement> surface
  - 외부 표면만 포함된 shell 요소 리스트
  - 노드 순서는 외부 법선 방향으로 정렬 (right-hand rule)

----------------------------------------------------------------
2. Offset 방향 결정
----------------------------------------------------------------

2.1 +normal / -normal 모드

  표면 법선 벡터의 평균을 계산하여 자연스러운 offset 방향 결정.

  단계:
    1) 각 표면 면의 법선 벡터 계산
       n = (P1 - P0) × (P2 - P0)
       n_unit = n / |n|

    2) 모든 면의 법선을 평균
       n_avg = Σ n_i / N

    3) +normal: n_avg 방향
       -normal: -n_avg 방향

  장점: 곡면 표면에서 자연스러운 offset
  주의: Concave 표면에서 self-intersection 가능

2.2 ±x / ±y / ±z 모드

  카테시안 축 고정 방향.

  예:
    +z: Vector3D(0, 0, 1)
    -x: Vector3D(-1, 0, 0)

  장점: 평면 표면에서 정확한 제어
  주의: 곡면에서 균일하지 않은 두께 발생 가능

----------------------------------------------------------------
3. 요소 생성 (Element Extrusion)
----------------------------------------------------------------

3.1 Solid Extrusion (HEX8)

  Layer-by-layer 노드 생성 후 solid 요소 연결.

  단계:
    1) Layer 0 (bottom): 원본 표면 노드 사용
       - Tied mode: 직접 사용
       - CZM/Contact: 복제 노드 생성

    2) Layer 1~N (top): 새 노드 생성
       for layer in 1..num_layers:
         newPos = origPos + direction * (layer * thickness / num_layers)
         newNode = ++maxNodeId_

    3) HEX8 요소 생성
       for each surface face:
         for layer in 0..(num_layers-1):
           bottom: layer 노드 (N0~N3)
           top:    layer+1 노드 (N4~N7)
           → HEX8 element

  노드 공유:
    - 인접 표면 면이 공유하는 노드는 하나의 노드만 생성 (dedup)
    - bottomToTopNodes[layer][origNodeId] → newNodeId 매핑 사용

3.2 TShell Extrusion (TSHELL3/4)

  Thick shell 요소는 top+bottom 노드를 모두 보유.

  노드 구조:
    TSHELL4 (8 nodes): [N0, N1, N2, N3]_bottom + [N4, N5, N6, N7]_top
    TSHELL3 (6 nodes): [N0, N1, N2]_bottom + [N3, N4, N5]_top

  ELFORM:
    16: TSHELL4 (quadrilateral)
    17: TSHELL3 (triangle)

  Layer-by-layer:
    각 layer는 독립된 top+bottom 노드 쌍 보유.

3.3 Shell Offset (QUAD4/TRIA3)

  단일 노드면만 생성 (no through-thickness nodes).

  단계:
    1) Offset 위치에 새 노드 생성
       newPos = origPos + direction * shell_offset

    2) 표면 면을 새 노드로 재구성
       Shell element with new node IDs

  두께:
    - *SECTION_SHELL의 T1~T4 필드에만 기재
    - 실제 노드는 mid-plane만 존재

----------------------------------------------------------------
4. Connection Modes
----------------------------------------------------------------

4.1 Tied Mode (노드 공유)

  구현:
    - Source 표면 노드를 offset 레이어 하단 노드로 직접 사용
    - 추가 처리 없음

  효과:
    - Perfect tie constraint (displacement compatibility)
    - 추가 키워드 불필요

  용도:
    - 완전 결합 레이어 (insulation, coating)

4.2 CZM Mode (Cohesive Zone Model)

  구현:
    1) Source 표면 노드 복제
       origNode → dupNode (동일 위치)

    2) Offset 레이어 하단 노드를 dupNode로 교체

    3) Zero-thickness cohesive elements 생성
       Bottom: origNode
       Top:    dupNode
       ELFORM=20 (zero-thickness solid)

  재료:
    *MAT_COHESIVE_MIXED_MODE (사용자 지정)
      - EN, ET: Normal/tangential stiffness
      - GIC, GIIC: Mode I/II fracture energy
      - T, S: Normal/shear strength

  효과:
    - 층간 분리(delamination) 모델링
    - Energy-based failure criterion

  용도:
    - Composite laminate delamination
    - Interface debonding

4.3 Contact Mode (완전 분리)

  구현:
    1) Offset 레이어 하단에 새 노드 생성 (동일 위치)

    2) *CONTACT_* 정의 template 주석 출력
       *CONTACT_AUTOMATIC_SURFACE_TO_SURFACE
         SSID = source_pid
         MSID = offset_pid

  효과:
    - 비결합(unbonded) 레이어
    - Contact algorithm으로 상호작용

  용도:
    - Sliding interface
    - Removable layer

  주의:
    - 사용자가 *CONTACT_* 키워드 수동 추가 필요
    - Friction coefficient 등 파라미터 설정

5. Dual Offset Prestress (Pouch Wrapping)
----------------------------------------------------------------

Battery pouch가 배터리 셀을 감싸는 과정을 시뮬레이션합니다.

5.1 물리 원리

  실제:
    1. Pouch가 평평한 상태에서 배터리 셀에 감김 (압축)
    2. Pouch가 탄성 회복하려 하지만 셀에 막힘 (prestress)

  모델링:
    1. Inner offset (음수): 압축된 형상 (deformed)
    2. Outer offset (양수): 릴랙스 형상 (reference)
    3. Reference 형상을 .k 파일에 출력
    4. Deformed → Reference 변형률 계산 → 역방향 응력
    5. DR 실행 시 reference → deformed 수축 (pouch 감싸기 재현)

5.2 Prestress 계산

  Full 3D strain tensor 사용 (squeeze와 동일 방법).

  단계:
    1) Reference configuration nodes
       refNodes[i] = 현재 요소 노드 위치 (outer offset)

    2) Deformed configuration nodes
       defNodes[i] = deformed position map (inner offset)

       - Bottom face: deformedPositions[nodeId]
       - Top face: refNodes[i] + (defNodes[bottom] - refNodes[bottom])

    3) Deformation gradient 계산
       Isoparametric mapping으로 F = dx_def / dX_ref 계산

       Reference vectors:
         dr_ref = ∂X/∂r at center (finite difference)
         ds_ref = ∂X/∂s
         dt_ref = ∂X/∂t

       Deformed vectors:
         dr_def = ∂x/∂r
         ds_def = ∂x/∂s
         dt_def = ∂x/∂t

    4) Metric tensor (small strain approximation)
       ε = 0.5 * (C - I)
       C = F^T * F (right Cauchy-Green tensor)

       ε_xx = 0.5 * (dr_def·dr_def / dr_ref·dr_ref - 1)
       ε_yy = 0.5 * (ds_def·ds_def / ds_ref·ds_ref - 1)
       ε_zz = 0.5 * (dt_def·dt_def / dt_ref·dt_ref - 1)

       Shear strains:
       ε_xy = 0.5 * (dr_def·ds_def / |dr||ds| - dr_ref·ds_ref / |dr||ds|)
       ε_yz, ε_xz 동일

    5) Hooke's law로 응력 계산
       σ = C : ε
       C: 4차 탄성 텐서 (isotropic: E, ν)

    6) 역방향 응력을 dynain에 출력
       *INITIAL_STRESS_SOLID (σ_xx, σ_yy, σ_zz, σ_xy, σ_yz, σ_xz)

5.3 Dynamic Relaxation 동작

  LS-DYNA DR 실행:
    1. t=0: Reference 형상 (outer offset, .k 파일)
    2. Prestress 로드 (역방향, .dynain)
    3. DR: 준정적 수축 (reference → deformed)
    4. 최종: Pouch가 배터리 셀을 감싼 압축 상태

  결과:
    - Pouch 내부 응력 분포
    - 배터리 셀 표면 압력
    - Contact force 분포

7. 검증 방법
----------------------------------------------------------------

7.1 표면 추출 검증

  단일 HEX8 (6면):
    - 출력: 6 shell elements
    - 각 면 4개 노드

  2 HEX8 공유면 (10면):
    - 출력: 10 shell elements (공유면 제외)

7.2 Extrusion 검증

  Solid (num_layers=2):
    - 노드: N_orig + (N_surface × 2)
    - 요소: N_surface × 2

  TShell (num_layers=1):
    - 노드: N_surface × 2 (top+bottom)
    - 요소: N_surface

7.3 Prestress 검증

  Dual offset with known displacement:
    inner_offset = -0.1 (compression)
    outer_offset = 0.0 (reference)

  Expected strain:
    ε_n ≈ -0.1 / thickness (normal)

  Expected stress:
    σ_n ≈ E · ε_n (reversed sign in dynain)

  DR 결과:
    - Final displacement ≈ -0.1 (return to deformed)
    - Residual stress ≈ 0

7.4 CZM 검증

  출력 확인:
    - Cohesive elements count = surface faces
    - *MAT_COHESIVE_MIXED_MODE 존재
    - *SECTION_SOLID ELFORM=20

  LS-DYNA 실행:
    - Zero initial separation
    - Mode I/II traction laws 활성화

8. 제한사항 및 주의사항
----------------------------------------------------------------

8.1 제한사항

  - Source 파트: Solid elements만 지원 (HEX8/TET4)
  - Shell element source 미지원 (shellmap으로 대체)
  - Self-intersection 감지 없음 (concave + +normal)

8.2 주의사항

  1. +normal 방향 self-intersection
     - Concave 표면에서 offset이 교차할 수 있음
     - LS-DYNA negative volume 경고
     - 해결: 고정 방향(±x/±y/±z) 사용 또는 offset 거리 감소

  2. CZM material 파라미터
     - Placeholder 값이 아닌 실제 시험 값 사용 권장
     - EN, ET: Interface stiffness (너무 작으면 불안정)
     - GIC, GIIC: Fracture energy (실험 데이터 필요)
     - T, S: Strength (peak traction)

  3. Dual offset prestress 요구사항
     - element_type = solid 필수
     - E, nu 지정 필수 (YAML material 섹션 또는 material_card)
     - inner_offset < outer_offset 권장

  4. Contact mode 수동 설정
     - 출력 .k 파일의 주석 템플릿 참조
     - Friction, penalty 등 파라미터 조정

  5. num_layers > 1
     - 각 층은 노드 공유 (node-shared)
     - 층간 요소 크기 균일
     - CZM은 최외각 interface만 적용
