# Context Notes — 리포트 블록 전수 노출

## 2026-10-13 — 발단은 "핫스팟 클러스터 들어있나" 였다

생성기(`koo_deep_report`)에는 **있었다** — `--hotspot-clusters` 로 상위 P%·거리계수·최소요소·
최대군집·판정기준(`von_mises` 등)을 받아 군집을 만들고, HTML 에 `DATA.hotspot` 으로 **탭까지**
붙인다(실측: 102 군집). 그런데 플랫폼 `normalize_deep` 은 그 키를 **읽지 않는다.**

★이것은 ④ 고아 절점 신호, `modelmeta` 2차 솔리드와 **같은 부류**다 — 상류에 데이터가 있고
플랫폼이 조용히 버린다. 세 번째다.

## 왜 '정규화가 아는 키만 통과' 가 계속 뒤처지는가

정규화는 **허용 목록**이다. 생성기가 키를 늘릴 때마다 플랫폼은 가만히 있어도 뒤처지고,
뒤처진 것이 **보이지 않는다**(에러도 경고도 없다). 그래서 이번에는 목록을 늘리는 대신
**일반 블록 접근**을 만든다 — 임베드 데이터의 모든 최상위 블록을 이름으로 꺼낼 수 있게.

그리고 **차집합 자체를 회귀로 고정**한다(A-2). 생성기가 키를 늘리면 그 회귀가 빨개져서
"새 것이 생겼다" 를 사람이 알게 된다. 허용 목록을 고치는 것을 **잊을 수 없게** 만드는 쪽이
허용 목록을 잘 관리하는 것보다 낫다.

## 조사에서 두 번 속았다 — 기록해 둔다

1. 처음에 키 이름을 `grep` 해서 '쓰인다/안 쓰인다' 를 갈랐다. **출력 필드명에 속았다** —
   `"min_principal"` 은 `parts_metrics` 의 **출력** 키라서 "쓰임" 으로 세어졌고, 하마터면
   "min 은 읽고 max 는 안 읽는 비대칭" 이라는 **없는 결함**을 보고할 뻔했다.
   → `data.get("…")` 로만 다시 셌다. **읽는 것과 쓰는 것을 같은 패턴으로 찾으면 안 된다.**
2. 블록 단위 차집합을 '하위 키 이름이 하나라도 겹치면 일부 전달' 로 셌더니 `hotspot` 이
   "1/36 전달" 로 나왔다 — 겹친 하나는 `part_id` 같은 우연이었다. 사실은 **0 전달**이다.
   → 어림짐작 지표는 **0 과 1 을 구분하지 못한다.** 정본은 `data.get` 전수였다.

## 2026-10-13 (이어서) — 이미지는 **두 곳**이 막혀 있었다

### ① 그림이 애초에 안 들어온다

결과 이미지는 리포트 HTML 안에 임베드되지 **않는다** — 옆에 딸린 파일이다. 그래서 "리포트를
올렸다" 와 "결과 그림이 플랫폼에 있다" 가 다른 사실이었다. 번들(.zip/.tar) 반입으로 고쳤다.

매핑은 리포트 자신이 정본이다 — `set_report.media[set][pos]` ↔ `positions[pos].id`.
실측으로 **25 위치 중 8 개만** 그림이 있고 17 항목은 **빈 항목**이었다(리포트 자신도
`note: "세트 산출물이 있는 위치: 8 / 25."` 로 적는다). 빈 항목을 건너뛰지 않으면 **그림이 없는
위치에 그림이 있다**고 말하게 된다.

★deep 리포트는 매핑을 **선언하지 않는다**(그림이 형제 `custom_report/` 에 있다). 그래서
파일명 규칙으로 케이스를 **추측하지 않고** 목록으로만 둔다 — 추측한 매핑은 틀려도 그럴듯하다.

### ② 들어와도 모델이 못 본다 — 이것이 진짜 공백이었다

`download_result` 는 base64 를 **dict 안에** 넣어 돌려준다. 그러면 모델에게는 **글자**로 온다 —
그림을 본 것이 아니다. 이 서버에 `ImageContent` 로 내는 길이 **한 곳도 없었다**.

★그리고 이것은 **수를 세는 관문으로 절대 안 잡힌다.** dict 에 base64 가 들어 있으면 호출은
"성공" 이고 길이도 그럴듯하다. 그래서 `reports_smoke.py` 가 **콘텐츠 블록의 종류**를 본다
(`ImageContent` 인가 · `mimeType` 이 `image/png` 인가). `stackdiagram` 꼬리말이 캔버스 밖에
찍히던 것과 같은 부류다 — **수는 맞는데 자리가 틀린** 결함.

### 실측으로 두 번 틀렸고 둘 다 회귀로 고정했다

1. **커밋 경계** — `ingest_report` 가 이미 커밋하고 돌아오므로, 뒤에서 `flush()` 만 하면
   미디어 칸이 사라진다. 반입 응답은 "16장 저장" 이라고 말하는데 `/media` 가 **0** 을 냈다.
   → 회귀가 `expunge_all()` 뒤 **다시 읽어** 확인한다.
2. **`path` + `role` 충돌** — `report_image(path=<mp4>)` 를 주면 기본 `role=peak` 가 그 mp4 를
   먼저 걸러 "그림이 없다" 는 **엉뚱한 까닭**을 댔다. 정작 "영상은 못 본다" 를 말하지 못했다.
   → `path` 가 있으면 `role` 로 걸러지 않는다.

★둘 다 "응답이 성공이라고 말하는데 사실이 다른" 모양이다. 그래서 회귀가 **응답을 믿지 않고
다시 읽거나 종류를 보게** 만들었다.

### 요약을 다시 계산하지 않기로 한 것

`doe_analysis`·`insights`·`physics` 의 하위 분석은 거의 모두 생성기가 계산한 `summary` 를
들고 있다. 내가 `per_position` 을 다시 집계하면 그 숫자가 **HTML 화면과 조용히 갈릴** 수 있다
(이 리포가 사본 문제로 이미 여러 번 치른 값이다). 그래서 `summary` 는 **그대로 올리고** 상세는
형태만 적고, 원본은 `get_block(path=…)` 으로 되짚게 했다.
