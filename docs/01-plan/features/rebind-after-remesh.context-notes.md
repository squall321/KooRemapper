# 결정 노트 — 재결속 v1

- **(2026-10-16) 실물 쌍이 없다.** 저쪽 작업 폴더에 `range_diff` 는 많지만(이동 3 · 다시 구움 3 인 표도 있다) 덱은 메시
  잡마다 덮어써 **전후 쌍이 남지 않는다**. 그래서 저쪽 형식 그대로의 합성 표로 시험한다 — `coord_sha` 는 오늘 저쪽 실물
  조각으로 값이 같음을 확인한 우리 `fragment::coordSha` 로 잰다.
- **파트 이름으로 가르는 까닭.** StepForge 덱은 파트마다 절점을 따로 둔다 — 맞닿은 두 파트(TIM·PCB)는 같은 자리에 절점이
  둘이다. 좌표만으로 찾으면 그 자리가 모두 「여럿」이 되어 못 푼다. 파트 이름은 `range_diff` 행 키(덱 파트 이름)와 같다.
