# 결정 노트 — modelmeta 2차 솔리드 null + reason

- **(2026-10-16) 누가 정했나.** 원장은 이것을 「사용자 판단 — 혼자 정하지 않는다」로 두었다. 직전 보고에 추천 없이
  질문으로 올렸고, 사용자가 「다 끝까지 마무리해」라고 한 뒤 「정해 달라던 것은 추천안으로 정한다」고 알렸다.
  그래서 **추천안으로 정하고 보고에 그 근거를 적는다** — 한 커밋이라 되돌리기 쉽다.
- **근거.** ① 이 파일의 질량 규약(유도 못 하면 null + reason)과 맞는다. ② 플래그를 안 읽는 소비자 둘이 틀린 숫자를
  그대로 싣는다. ③ 원장이 걱정한 「적재 소비자가 질량을 잃는다」 — 잃는 것은 −48.4% 틀린 숫자다. 소비자 다섯을 읽어
  모두 null 을 견딘다고 확인했다(kr2datahub 통과 · DataHub `components` 는 자유 dict · hwax-risk `_as_float(None)` →
  None · 프런트 `p.volume ? … : '–'` · 플랫폼 러너 통과).
- **P1-7 의 「기존 키 값 불변」 조건과의 관계.** 그 조건은 새 키를 더할 때 하류 파서를 지키려던 것이다. 이번은 **2차
  솔리드 파트에서만** 기존 키 값을 바꾸고, 바꾸기 전에 하류 파서를 전부 읽었다. 1차 덱은 바이트 불변을 시험으로 본다.
- **orphan_nodes 를 통째로 null 로 하지 않은 까닭.** 잘라 읽기는 참조를 줄이기만 한다 — 센 고아 ≥ 참 고아. 그래서
  센 값 0 은 참이고, 0 보다 크면 상한일 뿐이라 null + 사유(상한 값을 문구에 적는다).
- **bbox 를 그대로 둔 까닭.** 코너 넷이 앞 8칸에 다 있어 직선 변이면 맞다(실측). 곡선 변의 중간절점은 재지 않았다 —
  규약에 그렇게 적는다.
