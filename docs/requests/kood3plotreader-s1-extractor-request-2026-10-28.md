# KooD3plotReader 에 드리는 요청 — S1 경량 추출기 (2026-10-28)

**보내는 곳** DynaForge(KooRemapper) · 후처리 모듈
**받는 곳** KooD3plotReader
**성격** 요청입니다. 꼴은 제안이고, 정하는 것은 KooD3plotReader 입니다.
**총괄 계획** KooRemapper `docs/01-plan/features/drop-twin-1028.plan.md` — 이 요청은 계약 C-3 입니다. P0 실측은 `docs/04-report/drop-twin-p0-1028.report.md` §4 입니다.

## 1. 한 줄
각도마다 d3plot(이 덱 18 GB)에서 **겉면 변위 · 응력의 경량 추출본(S1, HDF5)** 을 만드는 도구를 KooD3plotReader 에 두고, 후처리 잡의 한 단계로 돌게 해 주십시오.

## 2. 왜 그쪽인가
- 리더 · `SurfaceExtractor` · `HDF5Writer` 가 이미 그쪽에 있습니다. 리더를 하나로 두면 d3plot 호환 위험이 생기지 않습니다.
- 지금은 메시만 쓰는 예제(`01_basic_hdf5_export`)뿐이고, 겉면과 상태를 함께 내는 도구는 없습니다.

## 3. 계약 C-3 — 제안 꼴
- **파일** — 각도마다 HDF5 하나. 원본 옆 run 폴더 아래에 둡니다(D-3, 예 `Output/s1.h5`).
- **`/mesh`** — 겉면 절점 id · 초기 좌표 · 면(4칸, 삼각은 넷째가 −1) · 면의 파트 id · 요소 id · 겉면 요소 id · 파트. 우리 원형 `/data/koopark/drop_twin_p0/s1_mesh_Run_20260602_093108_fd1418.h5` 와 같은 꼴입니다.
- **`/states`** — 시각 · 겉면 절점 변위 · 겉면 요소 von Mises · 요소 삭제 플래그.
- **`/sections`** — 기준 단면 조각(D-8). 축마다 한 장, 단면 위 다각형과 응력입니다. 단면 영상을 d3plot 없이 다시 그리는 데 씁니다.
- **속성** — 변환기 판 · 설정(시간 창 · 보폭 · 정밀도 · 제외 파트) · 원본 d3plot 경로 · 덱 sha256 · 표면 규칙 · 단위.
- **표면 규칙(StepForge 와 맞춤)** — 정렬한 고유 절점으로 본 면이 장치 솔리드 안에서 한 번만 나오면 겉면입니다. 육면체 6면에서 연달아 겹친 절점을 지우고 고유 절점 3개 미만인 면은 버립니다. 고유 절점이 4개인 요소(N1 N2 N3 N4 N4 N4 N4 N4 사면체)는 세 점 조합 넷입니다. 지정한 환경 파트(낙하판)는 뺍니다.
- **정본이 아닙니다** — 파트별 최대 응력의 정본은 리포트입니다. S1 은 보기와 학습용입니다.

## 4. 원형에서 배운 것 (10-28 실측, 11각도)
- 상태 4,952개 전부를 16비트 양자화 + int8 시간 델타로 쓴 원형이 각도당 204–670 MB(d3plot 의 1.1–3.7%), 2–4분, 2.6 GiB 였습니다. 시간 대부분은 d3plot 읽기였습니다.
- **크기는 압축보다 양자화 스케일이 정했습니다.** 전역 VM 스케일이 국소 피크에 묶이고, 델타 하나만 넘쳐도 단계를 통째로 저장해 델타가 거의 쓰이지 않았습니다(변위 단계의 70% 가 통째 저장, 넘친 값은 0.017%). 제안은 넷입니다.
  1. 파트별(양마다 파트별) 스케일.
  2. 값 단위 예외 목록 — 넘친 값만 따로 적고 단계는 델타로 둡니다.
  3. HDF5 `libver=latest` — 메타데이터가 파일마다 43.8 MB 에서 5.3 MB 로 줄었습니다.
  4. 상태 솎기 옵션(시간 창 · 보폭). 보기에는 수백 프레임이면 되고, 시험 재현은 카메라 fps 에 맞춘 창이 필요합니다.
- 메모리 — 전역 스케일을 정하려고 겉면 상태 전체(약 2 GB)를 올렸습니다. 두 번 읽기(스케일 먼저)로 상한을 두면 좋겠습니다.
- 게이트 — 파트마다 겉면 최대와 전 요소 최대, 그리고 「최대 요소가 겉면인가」 를 속성으로 남겨 주시면 DynaForge 게이트가 그대로 씁니다. 11각도에서 의미 있는 판정은 사면체 파트 1 뿐이었고, 2각도에서 최대 요소가 내부였습니다.
- 원형 스크립트(lasso + h5py)는 `/data/koopark/drop_twin_p0/s1_proto/` 에 있습니다. 참고만 하십시오.

## 5. 후처리 잡에 얹기
- 지금 deep report 가 d3plot 을 통째로 읽습니다(최대 RSS 34 GB). 같은 읽기에서 S1 을 쓰면 두 번 읽지 않습니다. 별도 단계로 할지는 그쪽이 정하십시오.
- 성패와 경고는 rc 와 본문으로 알려 주십시오(K-4 의 rc 3 꼴처럼). 일부 상태를 못 읽으면 조용히 줄이지 말고 실패나 경고로 드러내 주십시오.

## 6. 여쭐 것

2. 기준 단면 조각(D-8)의 꼴.
3. 일정과 순서 — 단면 영상 개선(P-2~P-4)과의 앞뒤는 그쪽이 정하십시오.
