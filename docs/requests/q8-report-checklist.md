## §2 신규 op 7종 — 여기서 되는지 판정

**판정 기준: Q8 덱이 없어도 수용 기준을 세울 수 있나.** 전부 합성 픽스처로 검증 가능하다 —
다만 분량이 크므로 작고 맞물리는 것부터 넣는다.

- [ ] **2-7 `neutralaxis`** — EI 가중 중립축. 합성 적층으로 손계산과 대조. 방금 문서화한 shellmap
      z=0 전제와 바로 맞물린다. ★먼저
      → 주의: `*MAT_VISCOELASTIC` 필드2 는 E 가 아니라 **BULK** 다(`E = 9KG/(3K+G)`).
        `*MAT_*_TITLE` 은 제목줄 1개를 건너뛴다.
      → 수용: `z_n = ΣEᵢtᵢzᵢ / ΣEᵢtᵢ` 를 손계산과 1e-9 이내로 일치.
- [ ] **2-2 `foldsurface`** — elastica BVP + `B` 이분법. **덱이 필요 없는 순수 수치**라 자기 검증이
      된다. 수용: 최소 곡률반경 = 목표(1e-6 이내) · 끝점 잔차 ≈ 0.
      → 주의: elastica 는 다중해다. **연속법으로 분기를 물려준 뒤** 이분법할 것(보고 실측:
        찬 초기값이 2.6배 틀린 분기를 집었다).
- [ ] **2-3 `refshell`** — QUAD4 기준 셸 생성. 수용: 현 합이 목표 길이와 0.01% 이내 · 종횡비 1:1 ·
      감김 `(a,d,c,b)` · Y 부호.
- [ ] **2-4 `stackwrap`(+`xcheck`)** — 기준면에 적층을 감고 `shellmap` 과 교차검증.
      수용: 두 방법의 좌표 차이가 메시 크기의 1/10 이내.
- [ ] **2-1 `linkage-fit`** — 링키지 역산. **알려진** 군별 강체변환을 걸어 접힘 덱을 합성하고 op 이
      그것을 되찾는지 본다(가장 강한 시험이 된다).
      → ★안전장치 필수: 군별 **피벗 산포**를 출력하라. 각도만으로 묶으면 조용히 틀린다
        (보고 실측 5.41mm).
- [ ] **2-5 `applyfold`** — 군별 변환을 큰 덱에 찍기. 수용: 바이트 크기 동일 · 되읽기 오차 ~0 ·
      미이동 0 · **bbox 가 기대 범위 안**.
      → ★안전장치 필수: ID 인덱스 배열은 **덱의 최대 ID** 로 잡는다(보고 실측: 절점 15.81M 인데
        최대 ID 17.85M, 712,103개가 조용히 누락됐다). 버린 개수가 0 이 아니면 실패.
- [x] **2-6 `elformat`** — **만들지 않는다. 필요가 없어졌다.**
      §1-1 이 이미 고쳐졌고 리더가 1줄·2줄을 다 읽는다(`KFileReader.cpp:535,603`). 회귀도
      `test_meshfix_two_line.py`·`test_element_card_layout.py` 로 지킨다. 보고의 우회책은 §1-1 이
      안 고쳐졌다는 전제에서 나온 것이고, 그 전제가 사라졌다. **문제가 사라진 기능을 만들지 않는다.**
