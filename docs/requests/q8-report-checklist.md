## §2 신규 op 7종 — 여기서 되는지 판정

**판정 기준: Q8 덱이 없어도 수용 기준을 세울 수 있나.** 전부 합성 픽스처로 검증 가능하다 —
다만 분량이 크므로 작고 맞물리는 것부터 넣는다.

- [x] **2-7 `neutralaxis`** — **넣었다.** `src/commands/neutralaxis.cpp` · `test_neutralaxis.py` 31건.
      층 = 파트. 솔리드 두께는 메시에서, 셸 두께는 `*SECTION_SHELL` 에서 읽는다.
      → 리더는 BULK→E 변환을 **이미 제대로 한다**(`KFileReader.cpp:1356~`, `nu` 까지).
        다만 `GI=0` 이면 재질을 아예 등록하지 않는다 — 그런 파트는 **제외하고 그렇게 말한다**.
        0 으로 쓰지 않는다. 쓸 층이 0개면 숫자를 내지 않고 rc=1 로 끊는다.
      → 수용 충족: `z_n = ΣEᵢtᵢzᵢ / ΣEᵢtᵢ` 를 **닫힌식**과 1e-9 이내로 일치(A-3). `D`·기하중심면·
        ΣE*t 도 같이 대조한다. 1e-9 을 버티려면 인쇄가 `%.12g` 여야 했다(`%.9g` 로는 못 버틴다).
      → 보고에 없던 것: 제 첫 경고 판정이 틀렸다. `|z_n| > 0.5·Σt` 로 "적층 밖" 을 말했는데 그 식은
        적층이 원점에 걸쳐 있을 때만 맞다. **적층의 실제 범위**로 판정하게 고쳤고 대칭 적층에서
        경고가 안 뜨는지(오탐)까지 시험에 넣었다(F-5~F-8).
- [x] **2-2 `foldsurface`** — **넣었다.** `src/commands/foldsurface.cpp` · `test_foldsurface.py` 32건.
      정점 곡률을 `κ0 = 1/R` 로 **고정**하니 미지수가 힘 매개변수 `B` 하나로 줄었다. 그리고
      `κ² = κ0² - 2B(1-cosθ)` 에서 **탐색 구간이 유한하게 닫힌다** —
      `B ≤ κ0²/(2(1-cos(α/2)))` 보다 크면 접선이 요구한 각에 **닿을 수가 없다.**
      → 다중해 대응: 그 닫힌 구간을 2만 점으로 **연속법으로 훑어 첫 교차**를 집는다. 찬 초기값에
        기대지 않으니 분기가 결정론적으로 정해진다(뒤집힘이 가장 적은 해).
      → 수용 충족: 최소반경은 **구조적으로** 목표와 같고(정점이 곡률 최대인지 다시 검사해서
        아니면 rc=1), 끝점 잔차는 2.2e-16 rad 이다(1e-8 넘으면 rc=1).
      → 자기 검증 3갈래: ① 원호 한계(α=L/R)를 **닫힌식**과 대조(현 `2R·sin(α/2)`, 높이
        `R(1-cos(α/2))`, 에너지 `L/2R²`, 곡선 전체 1e-9) ② 일반해를 **파이썬 독립 RK4** 와 대조
        ③ 보고된 B 보다 작은 쪽에 교차가 없음을 확인(첫 분기인지).
      → 보고에 없던 유용한 판정: `α > L/R` 이면 **불가능하다**(원호가 상한) — 필요한 R 과 L 을
        찍고 rc=1. `L ≫ R·α` 면 해가 물결이 되는데 그건 BVP 의 성질이지 solver 실패가 아니라,
        뒤집힘 수를 찍고 "한 방향 굽힘을 원하면 `arc_length ≈ R·α`" 를 권한다.
- [x] **2-3 `refshell`** — **넣었다.** `src/commands/refshell.cpp` · `test_refshell.py` 28건.
      곡선 CSV(`x`·`y` 칸을 **이름으로** 찾는다 — foldsurface 산출물이 그대로 맞는다)를 폭 방향
      +z 로 쓸어 구조화 QUAD4 덱을 낸다.
      → 기존 경로를 먼저 확인했다: `generate arc` → `extract-surface --face top` 이 이미 QUAD4
        기준 셸을 만든다. 하지만 **최소 굽힘반경을 지정할 수 없다** — 그래서 만들 값이 있다.
      → 수용 충족: 현 합 편차를 찍고 0.01% 넘으면 경고(`divisions` 를 주면 **등현 길이**로 다시
        뽑는다) · `width_divisions: 0` 이면 종횡비 1:1 · 감김 `(a,d,c,b)` 를 격자 공식으로 검사.
      → **Y 부호를 구전으로 두지 않았다.** `extract-surface --face top` 의 규약을 실측해 보니
        법선이 −z(몸체 안쪽)여서 맞출 정본이 없었다. 그래서 `(a,d,c,b)` 가 내는 법선이
        `ŵ × û` 임을 **직선 곡선에서 정확히 +y** 로 검사한다. 말이 아니라 수치다.
      → 만든 덱이 **우리 자신의 검증을 통과**하는지도 본다 — `info` 가 셸 야코비안을 따지지 않고
        (§1-7) 참조 무결성 0건이다(`*MAT_ELASTIC` 까지 써서 덱이 혼자 선다).
- [ ] **2-4 `stackwrap`(+`xcheck`)** — 기준면에 적층을 감고 `shellmap` 과 교차검증.
      수용: 두 방법의 좌표 차이가 메시 크기의 1/10 이내.
- [ ] **2-1 `linkage-fit`** — 링키지 역산. **알려진** 군별 강체변환을 걸어 접힘 덱을 합성하고 op 이
      그것을 되찾는지 본다(가장 강한 시험이 된다).
      → ★안전장치 필수: 군별 **피벗 산포**를 출력하라. 각도만으로 묶으면 조용히 틀린다
        (보고 실측 5.41mm).
- [ ] **2-5 `applyfold`** — 군별 변환을 큰 덱에 찍기. 수용: 바이트 크기 동일 · 되읽기 오차 ~0 ·
      미이동 0 · **bbox 가 기대 범위 안**.
      → ★안전장치 필수: ID 인덱스 배열은 **덱의 최대 ID** 로 잡는다(보고 실측: 절점 15.81M 인데
        최대 ID 17.85M, 712,103개가 조용히 누락됐다). 버린 개수가 0 이 아니면 실패.
- [x] **2-6 `elformat`** — **만들지 않는다. 필요가 없어졌다.**
      §1-1 이 이미 고쳐졌고 리더가 1줄·2줄을 다 읽는다(`KFileReader.cpp:535,603`). 회귀도
      `test_meshfix_two_line.py`·`test_element_card_layout.py` 로 지킨다. 보고의 우회책은 §1-1 이
      안 고쳐졌다는 전제에서 나온 것이고, 그 전제가 사라졌다. **문제가 사라진 기능을 만들지 않는다.**
