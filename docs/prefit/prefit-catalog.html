— 개 기능
MCP화란? 위 기능들은 개별 도구가 아니라 run_operation, describe_operation, list_operations 같은 소수의 MCP 도구로 감싸여 제공됩니다. 그래서 기능(op)이 늘어도 MCP 쪽 코드는 그대로이고, AI가 list_operations로 목록을 받아 run_operation으로 실행합니다. — 같은 카탈로그를 CLI · 웹 UI · MCP 세 경로가 공유합니다.
