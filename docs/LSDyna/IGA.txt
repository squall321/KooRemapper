$-------------------------------------------------------------------------------
$                             T E M P L A T E
$                   T R I M M E D   I G A   S O L I D S
$
$ Generic template for trimmed IGA solids with PID-embedding option TETMSH=-1
$ 
$ 1. Define a single and unique ID to be used in this input file for PID, SECID,
$    VID, SID, PATCHID, RID (e.g. ID must not be identical to other PIDs, SECIDs,
$    ... in the model): id
$ 2. Define material ID (same as MID of existing FE solid): mid
$ 3. Define the PID of the existing FE solid model to be embedded: fepid
$ 4. Define corner points of trivariate B-Spline Box (*IGA_3D_NURBS_XYZ): 
$    xmin, xmax, ymin, ymax, zmin, zmax
$ 5. Define desired element edge length in r-, s-, and t-direction (knot span 
$    size of triviariate B-Spline box *IGA_3D_NURBS_XYZ): rr, rs, rt
$ 6. Define integration rule (IR=0 reduced Gauss, IR=1 Full Gauss): ir
$ 7. Define light control point (LCP) stabilization parameters (recommendation: 
$    stabilization type styp=4, LCP threshold tollg=1.0e-3 may be increased in 
$    case of instabilities)
$     
$ All parameters are local, i.e. only active within this input file include. 
$ This allows using this template multiple times within the same model without
$ the need to change parameter names) (see PARAMETER_LOCAL in the LS-DYNA 
$ keyword users's manual VOL I).
$ 
$ The trivariate B-Spline Box is extended by one element in each direction
$ to cut-off boundary elements direction -> larger time step possible
$
$-------------------------------------------------------------------------------

$-------------------------------------------------------------------------------
$ Input End
